# 투자유치 사업계획서 체크리스트

## 제출/발표 전 필수 확인 사항

### Executive Summary
- [ ] 한 문단으로 핵심 전달 가능
- [ ] 문제-솔루션-시장-팀이 명확히 드러남
- [ ] 핵심 지표(KPI) 현재값 기재

### Problem & Solution
- [ ] 고객의 페인포인트가 구체적
- [ ] "있으면 좋겠다"가 아닌 "없으면 안 된다" 수준의 문제
- [ ] 솔루션이 문제를 직접적으로 해결
- [ ] 기존 대안 대비 차별점 명확
- [ ] 기술적 해자(moat) 설명

### Market
- [ ] TAM/SAM/SOM 구분하여 제시
- [ ] 시장 규모 출처 명시 (리서치 기관 보고서 등)
- [ ] 시장 성장률 근거 제시
- [ ] 타겟 고객 세그먼트 구체적 정의

### Business Model
- [ ] 수익 모델 명확 (어떻게 돈을 버는지)
- [ ] 가격 정책 근거 제시
- [ ] Unit Economics 계산 (CAC, LTV)
- [ ] LTV/CAC 비율 3x 이상 또는 개선 추세

### Competition
- [ ] 경쟁사 3개 이상 분석
- [ ] 경쟁 우위가 지속 가능한 근거
- [ ] 경쟁사를 과소평가하지 않음

### Traction
- [ ] 핵심 지표 성장 추이 제시
- [ ] 월별/주별 그래프 포함
- [ ] 주요 고객/파트너 실명 기재 (허가 시)
- [ ] 리텐션/이탈율 데이터

### Team
- [ ] 창업팀의 도메인 전문성 증명
- [ ] 핵심 팀원의 관련 경력 강조
- [ ] 팀 구성의 균형 (기술/사업/운영)
- [ ] 채용 계획과 투자금 연계

### Financial
- [ ] 3개년 재무 전망
- [ ] 매출 전망의 가정 명시
- [ ] 손익분기점 시점 제시
- [ ] 가정이 보수적이고 합리적

### The Ask
- [ ] 투자 금액 명시
- [ ] 자금 사용처 구체적 (비율 포함)
- [ ] 투자 후 12개월 마일스톤 제시
- [ ] Valuation 근거 (필요 시)

### 형식 및 발표
- [ ] 20페이지 이내 (본문 기준)
- [ ] 핵심 메시지가 3초 내 전달 가능
- [ ] 숫자와 그래프로 시각적 전달
- [ ] 오탈자/문법 검수 완료
