# 사내 R&D 기획서 체크리스트

## 제출 전 필수 확인 사항

### 프로젝트 개요
- [ ] 배경과 필요성이 회사 전략과 연결
- [ ] 프로젝트 목적이 한 문장으로 요약 가능
- [ ] 기대 성과가 정량적으로 측정 가능
- [ ] 성공 기준(KPI)이 명확히 정의

### 현황 분석
- [ ] 내부 역량(기존 기술/인력) 분석 포함
- [ ] 외부 환경(시장/경쟁) 분석 포함
- [ ] SWOT 분석 작성
- [ ] 분석 내용이 프로젝트 방향성과 연결

### 개발 계획
- [ ] 개발 범위(Scope) In/Out 명확
- [ ] 기술 접근 방법이 구체적이고 실현 가능
- [ ] 단계별 일정 현실적
- [ ] 마일스톤별 의사결정 사항 명시
- [ ] 산출물이 각 단계별 정의됨

### 투입 자원
- [ ] 필요 인력과 역할 명시
- [ ] 인력 투입률 현실적
- [ ] 예산 항목별 산출 근거
- [ ] 필요 인프라/도구 목록화
- [ ] 기존 자원 활용 방안 포함

### 리스크 관리
- [ ] 주요 리스크 3개 이상 식별
- [ ] 리스크별 대응 방안 구체적
- [ ] 외부 의존성 파악 및 대응 계획
- [ ] Go/No-Go 판단 기준 명시

### 사업화/활용 계획
- [ ] 단기/중장기 활용 계획 구분
- [ ] ROI 분석 포함
- [ ] 투자 회수 기간 제시
- [ ] 확장 가능성 언급

### 형식
- [ ] 경영진 대상 요약 1페이지 포함
- [ ] 전문 용어에 대한 설명 포함
- [ ] 승인 절차 및 승인자 명시
- [ ] 오탈자 검수 완료
