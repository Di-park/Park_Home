# 정부 R&D 과제 계획서 체크리스트

## 제출 전 필수 확인 사항

### 기본 요건
- [ ] 공고문의 지원 자격 요건 충족 확인
- [ ] 연구 기간이 공고 요건과 일치
- [ ] 연구비 총액이 공고 상한 이내
- [ ] 정부출연금/자기부담금 비율 요건 충족
- [ ] 참여율 합계 100% 이하 확인
- [ ] 과제 중복 여부 확인 (NTIS 검색)

### 1. 연구개발 과제 개요
- [ ] 과제명이 연구 내용을 명확히 반영
- [ ] 기술적 필요성 - 구체적 근거 제시
- [ ] 경제적/사회적 필요성 - 시장 데이터 인용
- [ ] 최종 목표가 정량적으로 측정 가능
- [ ] 세부 목표별 달성 기준 명시
- [ ] 연구개발 범위가 명확히 한정

### 2. 국내외 기술 동향
- [ ] 국내 기술 동향 - 최신 자료 기반 (최근 3년 이내)
- [ ] 국외 기술 동향 - 선진국 사례 포함
- [ ] 기술 수준 비교표 작성
- [ ] 특허 동향 분석 포함
- [ ] 논문/학술 동향 분석 포함
- [ ] 출처 및 참고문헌 명시

### 3. 연구개발 내용 및 방법
- [ ] 추진 체계도(조직도) 작성
- [ ] 세부과제별 연구내용 구체적 기술
- [ ] 연구방법이 실현 가능하고 구체적
- [ ] 핵심 기술의 차별성 명확히 기술
- [ ] 연차별 연구내용 구분 (다년 과제 시)

### 4. 연구개발 일정
- [ ] 간트 차트 또는 일정표 작성
- [ ] 마일스톤별 산출물 명시
- [ ] 일정이 현실적으로 달성 가능
- [ ] 중간 점검 시점 반영

### 5. 성과 및 활용 계획
- [ ] 정량적 성과 목표 (논문, 특허, 기술이전 등)
- [ ] 성과 목표가 현실적이고 측정 가능
- [ ] 사업화 전략 구체적으로 기술
- [ ] 후속 연구 계획 언급

### 6. 연구개발비
- [ ] 비목별 산출 근거 명확
- [ ] 인건비 참여율과 일치
- [ ] 연구비 편성 기준 준수 (비목별 상한 등)
- [ ] 위탁연구비 사유 명시 (해당 시)
- [ ] 연차별 연구비 합계 일치

### 7. 연구 인력
- [ ] 연구책임자 관련 분야 경력 기재
- [ ] 참여연구원 역할과 전문성 매칭
- [ ] 참여율이 적정 수준

### 8. 형식 및 기타
- [ ] 오탈자 검수 완료
- [ ] 페이지 수 제한 준수 (공고 확인)
- [ ] 그림/표 번호 및 제목 일관성
- [ ] 참고문헌 형식 통일
- [ ] 약어 첫 사용 시 풀네임 기재
