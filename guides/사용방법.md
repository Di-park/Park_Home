# 레포지토리 사용 가이드

## 빠른 시작

### 1단계: 프로젝트 시작
Claude에게 다음과 같이 요청하세요:

```
"AI 챗봇 개발" 정부 R&D 과제 계획서를 작성해줘.
```

Claude가 자동으로:
1. `templates/government/계획서_템플릿.md`를 기반으로
2. `projects/ai-chatbot-2026/` 디렉토리를 만들고
3. 계획서 초안을 작성합니다.

### 2단계: 사전 조사 요청
```
이 과제에 필요한 시장 동향과 기술 동향을 조사해서 research/ 에 정리해줘.
```

### 3단계: 섹션별 보강
```
계획서의 "국내외 기술 동향" 섹션을 보강해줘.
연구비 예산을 3억 원 규모로 작성해줘.
```

### 4단계: 체크리스트 점검
```
정부과제 체크리스트로 빠진 항목이 없는지 확인해줘.
```

## 유형별 사용 예시

### 정부 R&D 과제
```
IITP "인공지능 핵심 원천기술 개발" 사업에 지원할 계획서를 작성해줘.
과제명은 "대규모 언어모델 기반 코드 자동 생성 기술 개발"이고,
연구기간 2년, 총 연구비 10억 원 규모야.
```

### 투자유치 사업계획서
```
시리즈 A 투자를 위한 사업계획서를 작성해줘.
우리 서비스는 AI 기반 문서 자동화 SaaS이고,
현재 MAU 5,000명, MRR 3,000만원이야.
```

### 사내 R&D 기획
```
사내 R&D 기획서를 작성해줘.
내부 CS 자동화를 위한 AI 에이전트 개발 프로젝트이고,
예산 5억, 기간 6개월 규모야.
```

## 효과적인 활용 팁

### Claude에게 제공하면 좋은 자료
- **공고문 PDF/링크**: 정부과제의 경우 공고 요건을 정확히 파악
- **회사 소개서**: 연구 역량, 보유 기술, 인력 현황 파악
- **기존 계획서**: 작성 스타일과 수준 참고
- **기술 문서**: 개발하려는 기술의 상세 스펙
- **시장 보고서**: 시장 규모, 성장률 등 정량 데이터

### 효과적인 요청 방법
1. **구체적인 수치 제공**: "매출 10억" 대신 "2025년 매출 8억, 2026년 목표 15억"
2. **맥락 설명**: "AI 과제"보다 "의료영상 AI 진단 보조 시스템 개발 과제"
3. **기대 수준 명시**: "초안 수준" vs "제출 가능 수준"
4. **섹션별 작업**: 한 번에 전체보다 섹션별로 진행하면 품질 향상

### 버전 관리
- 주요 수정마다 커밋하여 변경 이력 관리
- 커밋 메시지 예: `[계획서] AI챗봇 과제 기술개발 섹션 작성`
- 피드백 반영 시 새 버전 파일 생성 (`_v1` → `_v2`)
