## 1. 과제 개요

- **과제 한 줄 정의**: 소상공인 현장에 분산된 고객 행동·상품 수요·마케팅 반응 데이터를 통합하여, **고객 분석 → 마케팅 판단 → 마케팅 실행 → 반응 학습**의 전 주기를 자동화하는 자가학습형 AI 에이전트 개발
- **개발 단계**: 5단계 (이탈예측 → 수요신호감지 → 문자 자가정제 → Depth 큐레이션 → 통합 실증)
- **자체 사전준비 TRL**: 6단계 수준
- **현재 운영 중인 파일럿**: 정육점 1개소 실서비스 (규칙 기반 분류 + LLM 문구 + 문자 발송)

## 3. 개발 배경 및 필요성 (원문 §1)

1. **AI 시대의 도래와 지식근로자 업무 자동화** — 생성형 AI 대중화로 영업·마케팅·고객관리 영역까지 에이전트 위임 단계 진입
2. **오프라인 소상공인의 AI 혜택 소외** — 골목상권 1인/소수 인력 구조, "누구나 AI로 자동화" 명제 비적용
3. **고객관리 영역의 디지털 격차 심화** — 대기업/이커머스는 풍부한 데이터 기반 개인화, 동네 가게는 사장님 기억에 의존. 범용 CRM은 사무직 세일즈 전제 설계 → 정육점 부위/명절/제철 등 업종 맥락 반영 불가
4. **현장 특화 AI 에이전트 도입 시점 도래** — 머신러닝 이탈/수요 예측 + LLM 개인화 텍스트 생성 기술이 실용 수준 도달, POS 로컬 데이터 활용 적기
5. **첫 도메인으로 정육점 선정 사유**
   - **단골 의존도**: 매출의 70% 이상이 단골 기반 반복 구매 → CRM 효용 직접 검증
   - **개인화 컨텍스트 다층성**: 부위·용도·가구단위·계절·명절 등 **5개 이상 도메인 축** 동시 활용 가능 (카페·편의점 대비 LLM 개인화 표현력 압도)

## 4. 5단계 연구개발 방법 (원문 §2)

### 4.1 1단계: 고객 이탈 예측 자가학습 모형 구축
- **목적**: 선행연구 이탈 정의 방법론을 5개 매장으로 확장 + 자가학습 기반 복합 이탈 점수 산출
- **알고리즘**: Random Forest (RF1: 방문주기, RF2: 객단가)
- **학습 단위**: 매장별 개별 모형 5개 + 통합 모형 1개
- **성능 목표**: 평균 **AUC 0.75 이상**, OOB 0.7 이상, F1 0.6 이상
- **자가학습 루프**: 월 1회 신규 데이터 반영 → 예측 불일치 라벨 자동 재조정 → 모형 재학습 → AUC 비교 기반 교체/유지

### 4.2 2단계: 품목 수요 신호 감지 자가학습 모형 구축
- **목적**: 1단계 복합 이탈 점수 + 판매 이력·날씨·고객 패턴 다변량 통합 → 타겟 고객 자동 추출
- **입력 변수**: 전년 동기 판매량, 지난달 판매량, 요일·계절·명절 여부, 기온·강수, 고객-품목 구매 패턴
- **성능 목표**: 주요 품목 평균 **MAPE 25% 이하**
- **자가학습 루프**: 월 1회 → 예측 오차 기여 변수 자동 분석 → 변수 재가중 → MAPE 비교 자동 판단

### 4.3 3단계: 개인화 문자 생성 자가정제 엔진 구축
- **목적**: 추론·사실 오류 최소화하는 정육점 특화 최적 프롬프트 + 판별기 기반 자가정제

**프롬프트 차수 설계**:
| 차수 | 버전 | 설명 |
|---|---|---|
| 0차 | P1 기본형 | 제약 없는 자유 생성 (베이스라인) |
| 1차 | P2 구조화형 | 도입부-품목언급-클로징 구조 |
| 2차 | P3 가게특화 | 부위-용도 매핑, 계절-고기 페어링 |
| 3차 | P4 추론조절 | 사실 제약 및 추론 허용 범위 조절 (최종) |

**개인화 Depth 설계**:
| Depth | 수준 | 입력 변수 |
|---|---|---|
| D1 | 모든 고객 동일 | 날씨·요일 등 외부 공개 데이터 |
| D2 | 구매 품목 맞춤 | D1 + 주요 구매 품목 |
| D3 | 개인 완전 맞춤 | D2 + 고객 이름·구매 패턴·단골 여부 |

- **성능 목표**: 최종 프롬프트 기준 평균 **오류 표현율 10% 이하**
- **검증**: G-Eval·한국어 특화 판별기, α=0.05 t-test/Mann-Whitney
- **자가정제 루프**: 실사용 오류 표현율 모니터링 → 기준값 초과 시 화이트리스트 자동 업데이트 → 프롬프트 재적용

### 4.4 4단계: 개인화 Depth별 마케팅 반응 자가학습 실험
- **실험 설계**: 5개 매장 분석 가능 고객, **주 3회 × 12주 = 36회**, within-person 순환 (D1→D2→D3→D2→D3...)
- **사전 분류**: 복합 이탈 점수 4분위(Q1 정상 / Q2 주의 / Q3 위험 / Q4 임박)
- **분석1**: Depth별 효과 — 패널 로지스틱 회귀
- **분석2**: 이탈 분위 × Depth 상호작용항 추가
- **자가학습**: Q분위별 반응률 모니터링 → 기준값 이상 하락 시 회귀 재수행 → 파라미터 자동 업데이트

### 4.5 5단계: 통합 자가학습 마케팅 의사결정 엔진 실증
- **실증 환경**: **30개 매장** 실사용 4개월
- **자가학습 모듈**: 1~4단계 통합 운영
- **큐레이션 성능 목표**: **추천 실행률 70% 이상** (시스템 로그 자동 수집)
- **모듈별 자가학습 추적 지표**:
  | 모듈 | 틀림 감지 기준 | 자가학습 방식 | 추적 지표 |
  |---|---|---|---|
  | 이탈 예측 | 예측 불일치 누적 | 라벨 재조정→재학습 | AUC 변화 |
  | 수요 신호 | 예측 오차 초과 | 변수 재가중→재학습 | MAPE 변화 |
  | 문자 생성 | 오류 표현율 초과 | 화이트리스트 업데이트 | 오류 표현율 변화 |
  | Depth 큐레이션 | Q분위 반응률 하락 | 회귀 재수행→파라미터 갱신 | 분위별 반응률 변화 |

- **연구명**: 개인별 3등분 방문 변화율 기반 고객 이탈 예측 모형 검증

- **활용 데이터**: 2024.04~2026.03 / 파일럿 정육점 1개소 / 거래 약 **51,000건** / 5회 이상 방문 고객 약 2,100명
