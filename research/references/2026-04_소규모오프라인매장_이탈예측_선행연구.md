## 1. 연구 배경

### 1.1 문제 인식
- 50~60대 소규모 오프라인 매장 점주는 디지털 취약계층
- 단골 고객의 이탈을 수개월이 지나서야 인지하며, 이 시점에는 이미 타 매장으로 이동 완료
- 대형 마트·이커머스는 AI 기반 이탈 예측을 운용하지만, 동네 정육점에는 이런 도구가 전혀 없음

### 1.2 기존 연구의 한계
| 기존 연구 | 한계 |
|----------|------|
| 이커머스 기반 이탈 예측 | 오프라인 소규모 매장에 적용 불가 |
| "왔다/안왔다" 이진값 이탈 정의 | 점점 뜸해지는 추세를 포착하지 못함 |
| 기업용 CRM 시스템 | 소상공인에게 비용·복잡도 면에서 부적합 |
| 소규모 오프라인 매장 특화 연구 | **전무** |

## 3. 핵심 방법론: 개인별 3등분 방문 패턴 분석

### 3.1 새로운 이탈 정의
> **"이탈은 사건(event)이 아니라 과정(process)이다"**
> "안 왔다"가 이탈이 아니라, "점점 덜 오고 있다"가 이탈의 신호

- 기존 방식(특정 기간 미방문 여부)의 문제점을 해결
- 방문 빈도가 줄어드는 **추세 자체**를 이탈 신호로 정의

### 3.2 개인별 3등분 방법론
- 각 고객의 "첫 방문일 ~ 마지막 방문일"을 개인 전체 기간으로 정의
- 이 기간을 3등분하여 **1구간(초반) / 2구간(중반) / 3구간(후반)**으로 분할
- 구간별 평균 방문 간격을 계산하여 변화 추세 파악
- 달력 기준이 아닌 **개인 기준** → 가입 시점이 다른 고객에게도 적용 가능

### 3.3 이탈 기준: 변화율 1.5
```
변화율 = 2→3구간 평균 방문 간격 ÷ 1→2구간 평균 방문 간격
```

| 변화율 | 의미 |
|--------|------|
| 0.8 미만 | 간격 짧아짐 (충성도 증가) |
| 0.8 ~ 1.2 | 거의 변화 없음 (안정적 단골) |
| 1.2 ~ 1.5 | 간격 약간 늘어남 (주의) |
| **1.5 이상** | **간격 50% 이상 늘어남 → 이탈 위험** |
| 2.0 이상 | 간격 2배 이상 → 이탈 임박 |

**1.5의 근거**: 전체 고객 2→3구간 변화율 중앙값이 **1.33** → 정상 고객도 후반부에 33% 느려지는 것이 자연스러움 → 1.5 이상을 정상 범위 벗어난 것으로 판단. **임의 설정이 아닌 데이터 기반 도출값.**

### 3.4 분석 대상 선정
| 단계 | 고객 수 | 사유 |
|------|---------|------|
| 전체 고객 | 3,589명 | |

## 6. 연구의 독창성 및 학술적 의의

1. **소규모 오프라인 매장 특화**: 기존 이탈 예측 연구는 전부 이커머스·구독 서비스 기반 → 오프라인 소규모 매장 특화 연구 최초
2. **과정 기반 이탈 정의**: 단순 미방문 이진값이 아닌, 방문 빈도 감소 추세를 이탈 신호로 포착
3. **개인별 3등분 방법론**: 고객마다 다른 기간을 개인화하여 분석 → 피처 중요도 47.6%로 타당성 입증
4. **데이터 기반 이탈 임계값**: 1.5라는 기준을 전체 고객 변화율 분포(중앙값 1.33)에서 도출

| 한계점 | 해결 방안 |
|--------|----------|

| 이탈 기준 1.5 미검증 | 다매장 통합 후 최적값 재산출 |

## 8. 특허 가능성 (3건)
1. **소규모 오프라인 매장의 개인별 방문 패턴 기반 이탈 기준 도출 방법** — 3등분 + 변화율 중앙값 기반 임계값 도출
2. **LLM 개인화 depth 기반 마케팅 메시지 생성·발송 시스템** — 이탈 확률별 depth 자동 결정 + 자동 발송
3. **멀티 매장 통합-개별 모델 전환 시스템** — 신규 매장 통합 모델 → 데이터 축적 시 개별 모델 전환
