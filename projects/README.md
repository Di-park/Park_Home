# 프로젝트별 계획서

실제 작성하는 계획서는 이 디렉토리 하위에 프로젝트별로 관리합니다.

## 사용 방법
1. 새 프로젝트 디렉토리 생성: `{project-name}/`
2. 해당 유형의 템플릿을 복사하여 작성 시작
3. 버전은 파일명에 `_v1`, `_v2` 등으로 관리

## 디렉토리 구조 예시
```
projects/
├── ai-chatbot-2026/
│   ├── 계획서_v1.md
│   ├── 계획서_v2.md
│   └── assets/          # 프로젝트별 첨부자료
└── cloud-platform-2026/
    ├── 계획서_v1.md
    └── assets/
```
