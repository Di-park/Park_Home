📎 본 과제와 자체 R&D의 관계: 본 과제는 ㈜위브원이 자체 R&D(병행 진행 중인 디딤돌 과제 RS-2026-25594825 “자가학습형 소상공인 현장 특화 고객관리 AI 에이전트”)로 개발한 AI 알고리즘(이탈 예측·수요 신호 감지·LLM 문구 자가정제·Depth 큐레이션)을 자체 보유 자산으로 탑재하여, 현장 매장에 실제로 배포·운영하는 시스템·플랫폼 계층을 개발하는 과제임. 자체 R&D는 알고리즘 연구에 한정되며, 본 과제는 POS 연동 미들웨어 + 디지털 취약 사용자 UX + 발송 인프라·운영 최적화에 집중하여 중복지원 우려를 배제함. 참고자료: research/references/2026-04_디딤돌_연구개발계획서_원문정리.md

1. 연구과제 개요

1.1 연구 개발의 중요성

가. 추진 배경 — “AI는 있는데, 현장에 가 닿지 못함”

  • 생성형 AI와 머신러닝 기반 고객관리 기술은 이미 실용 수준에 도달함.
  • 본 기관(㈜위브원) 또한 자체 R&D를 통해 소상공인 현장 데이터 기반 이탈 예측 모형(AUC 0.75), LLM 기반 개인화 문구 자가정제 엔진, 품목 수요 신호 감지 모형 등을 보유 중.
  • 그러나 이러한 AI 자산이 실제 매장에서 운영되기 위해서는, “AI 모델”과는 별개 차원에서 다음 3가지 시스템 계층의 동시 구현이 필수:
  1. POS 데이터 수집·정제 미들웨어 — 매장이 사용 중인 다양한 POS(키오스크·포스뱅크·OK포스 등)에서 거래·고객·품목 데이터를 표준 스키마로 자동 수집하는 통합 계층
  2. 디지털 취약 사장님 대상 앱·태블릿 UX — 50~60대 자영업자가 학습 부담 없이 “버튼 한 번”으로 사용 가능한 운영자 인터페이스
  3. 메시지 발송 인프라 및 운영 최적화 엔진 — SMS·LMS·카카오 알림톡 통합 발송, 발송 큐·비용 최적화, 메시지 피로도(message fatigue) 관리, 발송 타이밍 자동 최적화
  • 본 과제는 위 3개 시스템 계층을 핵심 개발 범위로 정의하고, 자체 보유 AI 자산을 탑재하여 “매장에서 실제로 동작하는 AI CRM 문자 발송 플랫폼” 의 완성을 최종 목표로 함.
  • 즉, 본 과제의 결과물은 “AI 모델 그 자체” 가 아니라, AI를 현장으로 전달하는 “시스템·플랫폼” 임.

나. 기술적 필요성

1) POS 통합 미들웨어의 부재 — 데이터가 매장에 갇혀 있는 구조

  • 국내 소상공인 매장이 사용하는 POS는 키오스크·포스뱅크·OK포스·삼성SDS·아임유 등 10개 이상 사업자가 파편화된 시장을 형성하고 있음.
  • 각 POS마다 (i) 데이터 스키마, (ii) 추출 방식(API·DB 덤프·CSV·로컬 파일), (iii) 고객 식별자 체계가 상이함.
  • 결과적으로 AI 솔루션이 아무리 우수해도 매장의 1차 데이터를 실시간으로 가져올 표준 경로 자체가 부재.
  • 본 기관 자체 R&D 파일럿 단계에서도 사장님이 월 1회 수동으로 자료를 제공해야 하는 한계가 확인되었으며, 이는 데이터 신선도(freshness) 저하 및 실시간 마케팅 자동화 불가의 직접적 원인임.
  • 본 과제는 다양한 POS 사업자 대상 표준 스키마 자동 매핑·정제 미들웨어(목표 매핑 정확도 95%) 를 구현하여 위 구조적 병목을 해소.

2) 디지털 취약 사용자 대상 UX의 부재

  • 소상공인 사장님의 70% 이상이 50~60대이며, 스마트폰·태블릿 기반 디지털 도구의 학습 부담이 마케팅 자동화 솔루션 도입의 최대 장벽으로 작용 중.
  • 시중 CRM 솔루션(채널톡·도도포인트·해피포인트 등)은 사무직 데스크탑 환경을 전제로 설계되어 현장 즉시 사용 가능한 모바일·태블릿 UX의 공백이 큼.
  • 본 과제는 다음 4가지 UX 원칙 기반의 인터페이스를 설계:
    • 알림 → 확인 → 승인 → 발송의 4-step 단순 흐름 (운영자 의사결정 부담 최소화)
    • “왜 이 고객인가” 자연어 설명 (AI 추천 사유를 사장님 언어로 시각화하여 신뢰도 확보)
    • 태블릿 매장 디스플레이 + 사장님 스마트폰 앱의 이중 채널 (영업 중·외 환경 모두 대응)
    • 고연령 친화 디자인 가이드라인 적용 (글자 크기 16pt 이상, 색상 대비 4.5:1 이상, 음성 안내 보조)

3) 발송 인프라 및 운영 최적화 엔진의 부재

  • 문자 마케팅은 단순한 “문자 발송 행위”가 아니라 채널 선택(SMS/LMS/알림톡) · 비용 최적화 · 발송 큐 운영 · 피로도 관리 · 타이밍 최적화 의 다중 의사결정이 결합된 운영 문제임.
  • 시중 발송 대행 서비스는 단순 채널 라우팅만 제공하고, 개별 고객 단위의 피로도·반응성·발송 시점을 통합 최적화하는 운영 엔진은 시장에 부재.
  • 본 과제는 다음 4개 운영 최적화 기능을 시스템 핵심 모듈로 개발:
    • 채널 자동 라우팅: 발신자 프로필·수신자 등록 여부·메시지 길이·비용에 따라 알림톡 → LMS → SMS 자동 폴백
    • 메시지 피로도 관리: 고객별 직전 발송 이력·반응 이력·이탈 위험도를 결합한 개인별 발송 빈도 상한 자동 산출
    • 발송 타이밍 최적화: 고객별 과거 응답 시간대·요일·계절·매장 영업 패턴 기반 개인 최적 타임슬롯 큐 배정
    • 발송 비용 최적화 대시보드: 캠페인 단위 채널 믹스·반응률·ROI 자동 집계

다. 자체 보유 AI 자산과 본 시스템의 시너지

  • 본 기관은 자체 R&D(병행 진행 디딤돌 과제)를 통해 다음 4개 AI 모듈을 이미 확보·고도화 중인 자산으로 보유:
자체 보유 AI 자산 본 시스템에서의 역할
① 이탈 예측 RF 복합 모형 (AUC 0.75 검증) 시스템 데이터 레이어에서 호출 → 사장님 앱의 “이탈 위험 고객 알림” 화면에 표시
② 품목 수요 신호 감지 모형 (MAPE 25% 이하 목표) “이번 주 판매가 떨어진 품목 + 그 품목을 사가던 고객” 자동 매칭 결과를 UI에 표시
③ LLM 개인화 문구 자가정제 엔진 (오류율 10% 이하) 발송 인프라에서 호출하여 Depth별 문구 자동 생성, 사장님 검수 화면에 표출
④ Depth 큐레이션 모형 발송 큐의 채널·타이밍·문구 Depth 결정에 입력 신호로 활용
  • 본 과제는 위 4개 AI 자산을 API 형태로 시스템 내부에 탑재하고, 그 출력을 (i) POS 통합 미들웨어 입력으로 수신 → (ii) 사장님 UX에서 검수 가능하게 시각화 → (iii) 발송 인프라·운영 최적화 엔진을 통해 실제 메시지로 전달하는 End-to-End 파이프라인을 완성.
  • AI 모델 자체의 정확도 개선은 자체 R&D 영역이며, 본 과제는 그 모델이 현장에서 동작하도록 만드는 시스템·플랫폼 계층에 집중함으로써 자체 R&D와 명확한 경계 및 상호보완 관계를 유지.

라. 경제적·사회적 필요성

1) 경제적 측면

  • 솔루션 도입 매장 평균 매출 향상 15% (자체 R&D 파일럿 기준 추정치 / 본 시스템 30개 매장 실증에서 정량 검증 예정)
  • 소상공인 마케팅비 절감 50% 이상 — 기존 문자 마케팅 대행 단가 대비, 발송 인프라 직접 운영·자동 채널 라우팅을 통한 절감
  • 첫 진입 시장: 정육점 약 57,000개소 · 2,200억 원 규모. 대형 플랫폼·대기업 CRM이 진입하지 않은 미개척 시장
  • 1차 확장 시장: 식품 관련 소매·외식 약 90만 개 · 1조 원
  • 최종 목표 시장: 재방문 기반 B2C 소상공인 약 300만 업체 · 7조 원

2) 사회적 측면

  • AI 격차 해소: AI 모델은 이미 존재하지만 “현장에 닿지 않던” 구조적 격차를 시스템·UX 계층에서 직접 해소
  • 디지털 취약산업 포용: 50~60대 자영업자 대상 UX 연구를 별도 트랙으로 수행하여 기술 포용(tech inclusion) 실현
  • 지역 경제 활성화: 동네 소상공인의 단골 유지율 향상을 통한 지역 상권 활성화 기여
  • 국가적 레퍼런스: 본 시스템 검증 시 마트·반찬가게·미용·헬스케어 등 인접 오프라인 산업으로 시스템·UX 자산 그대로 확장 가능 — 정부 소상공인 디지털 전환 정책(연 수천억 원·50만 명 목표)의 핵심 인프라로 자리매김

마. 첫 적용 도메인으로 정육점을 선정한 사유

본 시스템의 첫 적용·실증 도메인을 정육점으로 선정한 사유는 다음과 같음.

  1. 단골 의존도의 압도적 우위: 정육점 매출의 70% 이상이 단골 기반 반복 구매에서 발생 — CRM 시스템 효용이 가장 직접적으로 검증되는 도메인
  2. POS 데이터 가용성: 오프라인 대면 판매·POS 기반 결제가 주류로 고객 데이터가 플랫폼(배달앱 등)에 종속되지 않는 구조 — 본 과제 POS 통합 미들웨어가 정상 동작 가능한 환경
  3. 플랫폼 종속성 부재: 음식점·카페와 달리 배달앱 영향이 미미하여 독립 솔루션의 가치 창출 공간 확보
  4. 개인화 컨텍스트 다층성: 부위·용도·가구단위·계절·명절 등 5개 이상 도메인 축 — 본 시스템에 탑재된 AI 자산의 표현력이 가장 잘 발현되는 환경
  5. 자체 보유 협력 네트워크: 연 매출 1,000억 원 규모 정육 유통사(더담우)와의 협력 MOU 보유 — 시스템 실증 매장 확보 및 확산에 즉시 활용 가능

바. 본 연구의 차별적 의의

  • 본 연구의 차별점은 다음 한 줄로 요약:

“AI 모델”이 아니라 “AI를 현장에 가 닿게 하는 시스템” 의 개발

  • 글로벌 CRM(Salesforce·HubSpot·Braze): 온라인 이벤트 기반, 사무직 데스크탑 UX, POS 통합·디지털 취약 UX 부재

  • 국내 SMB CRM(채널톡·도도포인트·해피포인트): 멤버십·쿠폰 중심, AI 미탑재, 발송 운영 최적화 부재

  • 본 과제: 다양한 POS 통합 미들웨어 + 디지털 취약 사장님용 앱/태블릿 UX + 발송 인프라·운영 최적화 엔진 + 자체 보유 AI 자산 탑재 — 시장 미선점 영역의 4중 결합

  • 또한 본 기관이 자체 R&D로 보유한 AI 자산(이탈예측·수요예측·문구 자가정제·Depth 큐레이션)은 본 시스템 결합 시 즉시 차별화 가능한 기보유 자산이며, 협력사 더담우의 영업망은 본 시스템 시장 확산 속도에 직접 기여.

1.2 연구 개발 대상 기술의 국내외 현황

본 과제의 핵심 요소기술은 AI 모델이 아니라, 그 AI를 매장으로 가 닿게 하는 시스템·플랫폼 계층의 다음 4개 영역임.

  • (A) POS 통합 미들웨어 — 다양한 POS 사업자에서 거래·고객·품목 데이터를 표준 스키마로 자동 수집·정제하는 데이터 계층
  • (B) 디지털 취약 사장님 대상 모바일·태블릿 UX — 50~60대 사용자가 학습 부담 없이 사용하는 운영자 인터페이스
  • (C) 발송 인프라·운영 최적화 엔진 — SMS·LMS·카카오 알림톡 통합 발송, 채널 라우팅, 발송 큐, 피로도·타이밍·비용 최적화
  • (D) AI 자산 통합 시스템 아키텍처 — 자체 보유 AI 모델을 API 형태로 탑재하고 운영자 UX·발송 인프라와 연결하는 End-to-End 파이프라인

1.2.1 국내외 기술 수준

요소기술 세계 최고 수준 (해외) 국내 평균 수준 본 과제 목표 격차·진입 전략
(A) POS 통합 미들웨어 Toast·Square·Lightspeed 등 통합 POS-CRM 자체 보유 (북미는 POS 사업자 자체가 CRM 일체화). 독립 미들웨어는 Toast Partner Ecosystem·Square App Marketplace 수준 도도포인트·테이블링 등이 일부 POS사와 개별 연동, 표준 스키마 자동 매핑 솔루션 부재 매핑 정확도 95% (8개 이상 POS 사업자 지원) 국내 POS 시장 파편화 → 빅테크 비진입 영역, 한국 POS 사업자별 어댑터 + 표준 정제 레이어로 선점
(B) 디지털 취약 UX Square Dashboard·Toast Now 등 영문권 사장님용 모바일 UX 성숙 채널톡·도도포인트 등 사무직 데스크탑 전제, 태블릿·고연령 친화 UX 사례 부재 SUS(System Usability Scale) 80점 이상, 사장님 1회차 온보딩 완료율 90% 한국 50~60대 자영업자 인터뷰·관찰 연구 기반 UX 가이드라인 신규 정립
(C) 발송 인프라·운영 최적화 Braze · Iterable · Customer.io 등 글로벌 마케팅 자동화 플랫폼이 채널 라우팅·피로도 관리 기능 보유 (단, 한국 알림톡 미지원) 비즈엠·알리고·KT BizM 등 발송 대행은 단순 라우팅만 제공, 피로도·타이밍·비용 통합 최적화 엔진 부재 발송 성공률 99% / 채널 비용 자동 절감 30% / 개인별 피로도 임계 자동 산출 한국 알림톡 심사 규정 + 통신사 SMS·LMS + 글로벌 마케팅 자동화 운영 원리를 결합한 한국형 운영 최적화 엔진
(D) AI 자산 통합 아키텍처 Salesforce Einstein·HubSpot AI 등이 자사 AI 모델을 시스템에 임베드한 형태 본 기관 자체 R&D AI 모델 보유 + 시스템 측 임베드 인프라 자체 개발 필요 AI 모듈 API 응답 평균 1.5초 이내, 모듈 4개 통합 운영 자체 보유 모델 + 자체 시스템 인프라로 수직 통합 — 외부 의존 없음

격차 분석 요약: A·B·C 영역 모두 해외에는 일정 수준 사례가 있으나 한국 시장 특수성(파편화된 POS, 알림톡 심사, 고연령 사용자) 으로 인해 글로벌 솔루션의 직수입이 불가능한 영역임. 국내에는 부분적 사례만 존재하고 4개 영역을 수직 통합한 솔루션은 부재. 본 과제는 이 통합 영역의 선점을 목표로 함.

1.2.2 국내외 연구·산업 동향

1) POS 통합 미들웨어 동향

  • 해외: Toast(미국 외식업 POS·CRM 1위), Square, Lightspeed 등은 POS와 CRM을 일체형으로 자체 보유하는 구조로 별도 통합 미들웨어 시장이 상대적으로 작음. 다만 Toast Partner API·Square App Marketplace는 3rd party 솔루션을 위한 표준 데이터 인터페이스를 공개하여 미들웨어 사업자가 자생 가능한 생태계 형성 중.
  • 국내: 키오스크·포스뱅크·OK포스·삼성SDS·아임유·KIS정보통신·하이멕스 등 10개 이상 POS 사업자가 시장을 분점하고 있으며, 각 POS의 데이터 인터페이스가 표준화되어 있지 않음. 산업계에는 도도포인트·테이블링 등이 일부 POS와 개별 연동을 진행 중이나 “어느 POS든 동일하게 동작하는 통합 미들웨어”는 시장에 부재.
  • 본 과제 위치: 첫 출시 시점 8개 이상 주요 POS 어댑터 확보 + 표준 정제 레이어 구현을 통해 국내 미선점 영역의 선제 진입.

2) 디지털 취약 사용자 UX 연구 동향

  • 해외: HCI(Human-Computer Interaction) 학계에서 “Older Adults · Aging in Place · Low-literacy Users” 대상 UX 연구가 활발 (ACM CHI·CSCW 다수 논문). 산업적으로는 Square Dashboard·Toast Now가 모바일 사장님 UX의 베스트 프랙티스로 인용됨.
  • 국내: 정부 디지털 포용 정책 영향으로 공공 서비스 영역(정부24·건강보험·은행)에서 고연령 UX 가이드라인 일부 등장. 그러나 B2B SaaS·CRM 영역에서 고연령 자영업자 대상 UX 연구·표준은 사실상 부재.
  • 본 과제 위치: 본 기관 자체 R&D 파일럿(정육점 1개소·실서비스 운영)에서 사장님 실사용 인터뷰·관찰 데이터 축적 중이며, 본 과제에서는 이를 5개 매장 → 30개 매장으로 확장하여 한국 정육점·소상공인 도메인 특화 UX 가이드라인을 정립. KAIST·서울대 등 학력 기반 UX 연구자(SEO CHARLES, ㈜팬블러 PO 출신)를 핵심 인력으로 보유, 학계 표준에 부합하는 실증 설계 가능.

3) 발송 인프라·운영 최적화 동향

  • 해외: Braze·Iterable·Customer.io·MoEngage 등 모바일 마케팅 자동화 플랫폼은 채널 라우팅, 피로도 관리(frequency capping), Send Time Optimization(STO), 이탈 예측 연동을 표준 기능으로 탑재. 그러나 한국 카카오 알림톡 미지원, 비용 구조가 한국 시장과 상이함.
  • 국내: 비즈엠·알리고·KT BizM·LG U+ 모바일 등 발송 대행 사업자는 통신사 SMS·LMS와 알림톡 채널 라우팅의 기본 인프라만 제공하며, 피로도·타이밍·캠페인 ROI 통합 최적화 운영 엔진은 미제공. 카카오 i Connect·NHN INISMS 등도 동일 수준.
  • 본 과제 위치: 한국 알림톡 심사 규정 및 통신사 SMS·LMS 비용 구조를 반영한 한국형 발송 운영 최적화 엔진을 시스템 내부 모듈로 구현. 글로벌 마케팅 자동화 플랫폼의 운영 원리(STO·frequency capping·channel orchestration)를 한국 시장에 이식.

4) AI 모델의 시스템 통합 동향

  • 해외: Salesforce Einstein, HubSpot AI, Adobe Sensei 등 자사 AI 모델을 자사 CRM 시스템에 임베드하는 수직 통합이 일반화. OpenAI API·Anthropic API를 외부에서 호출하는 형태와 병행.
  • 국내: 네이버 클로바·카카오 헤이카카오 등이 자사 플랫폼에 AI를 임베드. 그러나 소상공인 CRM 영역에 자체 AI를 임베드한 사례는 미진.
  • 본 과제 위치: 본 기관 자체 R&D(디딤돌) 보유 AI 모델을 본 시스템 내부에 API 형태로 임베드하여 외부 LLM 의존도를 낮추고 시스템 응답 속도·비용·보안을 동시 확보. AI 모듈 API 응답 평균 1.5초 이내 목표로 매장 현장 실시간성 보장.

  • 특허 출원 3건 (본 과제 범위)

    2. 디지털 취약 사용자 대상 4-step CRM 운영자 UX 구조 및 모바일·태블릿 이중 채널 인터페이스 시스템

나. 1단계 — POS 통합 미들웨어 개발
  • 연구 내용
    1. POS 사업자별 데이터 인터페이스 조사·문서화: 키오스크·포스뱅크·OK포스·삼성SDS·아임유·KIS정보통신·하이멕스·이지웨이 등 주요 8개 이상 POS의 데이터 추출 방식(API·로컬 DB·CSV·OSC) 분석
    2. 표준 스키마 설계: 거래·고객·품목·결제 4개 엔티티의 표준 스키마 정의 (POS별 컬럼 매핑표 작성)
    3. 데이터 품질 자동 검증 규칙 도출: 결측·이상치·중복·식별자 충돌 케이스 정의 및 정제 규칙 수립
  • 기술 개발
    1. POS별 어댑터 (8개 이상) — 각 POS의 인터페이스에 맞춘 데이터 수집 클라이언트
    2. 표준 스키마 자동 매핑·정제 엔진 — 컬럼명 추론, 단위 정규화, 고객 식별자 통합, 이상치 자동 처리
    3. 데이터 품질 대시보드 — 매장별 데이터 신선도·결측률·이상치율 자동 모니터링
    4. 신규 매장 자동 온보딩 파이프라인 — POS 식별 → 어댑터 자동 선택 → 초기 데이터 적재 → 품질 검증 자동 실행
다. 2단계 — 사장님 앱·태블릿 UX 개발
  • 연구 내용
    1. 고연령 자영업자 사용성 인터뷰·관찰 연구: 자체 R&D 파일럿 매장 + 5개 매장 확장 사장님 실사용 관찰(매장별 8시간 이상), 사용성 문제 리스트화
    2. 고연령 친화 UX 가이드라인 정립: 글자 크기·색상 대비·음성 안내·터치 영역·정보 위계 등 8개 항목 가이드라인 수립
    3. 4-step 운영 흐름 검증 실험: 알림 → 확인 → 승인 → 발송의 단순 흐름이 의사결정 부담을 충분히 낮추는지 SUS·NASA-TLX 측정
  • 기술 개발
    1. 사장님 모바일 앱 (iOS/Android) — React Native 기반, 알림 + 발송 승인 + 결과 확인 기능
    2. 매장 태블릿 앱 — 영업 중 상시 비치용 대화면 UX, 단골 방문 시 이름·구매 이력 자동 표시
    3. AI 추천 사유 자연어 설명 모듈 — “왜 이 고객에게 보내야 하는가” 를 사장님 언어로 자동 설명 (예: “3주째 안 오시던 단골 분이세요. 평소 삼겹살을 자주 사가셨어요.”)
    4. 고연령 친화 디자인 시스템 — Figma 기반 디자인 토큰·컴포넌트 라이브러리
    5. 온보딩 워크플로우 — 매장 등록·POS 연결·초기 고객 데이터 확인까지 자동 가이드
라. 3단계 — 발송 인프라·운영 최적화 엔진 개발
  • 연구 내용
    1. 카카오 알림톡 심사 규정·통신사 SMS·LMS 단가·발송 시간 제약 정리: 한국 시장 특수 규제·비용 구조 매핑
    2. 메시지 피로도(message fatigue) 모델 설계: 고객별 직전 발송 이력·반응 이력·이탈 위험도를 결합한 개인별 발송 빈도 상한 자동 산출 규칙
    3. 개인 최적 타임슬롯(Send Time Optimization) 모델 설계: 고객별 과거 응답 시간대·요일·계절·매장 영업 패턴 결합
  • 기술 개발
    1. 채널 자동 라우팅 모듈 — 발신자 프로필·수신자 등록·메시지 길이·비용·심사 통과율을 종합한 알림톡 → LMS → SMS 자동 폴백
    2. 발송 큐 시스템 — 분산 큐(Redis/Kafka 기반) + 우선순위 + 재시도 + 실패 알림
    3. 피로도 관리 엔진 — 고객별 임계 자동 산출, 초과 발송 자동 차단
    4. 타이밍 최적화 엔진 — 개인 최적 타임슬롯 큐 배정, 매장 영업시간 준수
    5. 비용 최적화 대시보드 — 캠페인 단위 채널 믹스·반응률·ROI·예상 비용 자동 집계
    6. 발송 성공률·실패 분석 모니터링 — 채널별 성공률·실패 사유 자동 집계
마. 4단계 — AI 자산 통합 + 베타 서비스
  • 연구 내용
    1. AI 자산 API 인터페이스 설계: 자체 R&D 보유 4개 AI 모듈(이탈 예측·수요 신호·문구 생성·Depth 큐레이션)을 시스템 내부 API로 노출하는 인터페이스 명세 작성
    2. End-to-End 데이터 흐름 검증: POS 데이터 → AI 모듈 → UX 화면 → 발송 인프라 → 발송 이력 → 매장 데이터로 환류되는 전체 흐름 점검
    3. 시스템 응답 성능 최적화: AI 모듈 API 응답 P95 1.5초 이내 달성을 위한 캐싱·배치·비동기 처리 설계
  • 기술 개발
    1. AI 모듈 임베드 게이트웨이 — 자체 R&D 모듈을 내부 마이크로서비스로 배포·호출, 인증·로깅·모니터링 일체화
    2. End-to-End 통합 파이프라인 — POS → AI → UX → 발송의 단일 데이터 흐름 + 발송 결과의 AI 측 환류
    3. 베타 서비스 운영 환경 — 5개 매장 대상 베타 배포, 24/7 운영 모니터링, 장애 알림
    4. 다중 매장 운영 콘솔 — 본 기관 운영자(CS·기술팀)가 30개 매장 전체를 한 화면에서 관리
바. 5단계 — 30개 매장 통합 실증
  • 연구 내용
    1. 실증 환경 구축: 30개 매장 순차 온보딩, POS 어댑터 8종 이상에서 발생하는 실제 데이터 처리 검증
    2. 운영성 정량 측정: 시스템 가동률·발송 성공률·평균 응답시간 등 시스템 측 KPI 자동 수집
    3. 사업화 가능성 정량 측정: 매장별 발송 ROI(매출 변화·재방문 변화·마케팅 비용 절감)·운영자 만족도(SUS·NPS)·큐레이션 승인율 측정
    4. 사용성 보조 분석: 4개월간 사장님 행동 로그 분석을 통한 UX 개선점 도출
  • 기술 개발
    1. 30개 매장 통합 배포 파이프라인 — 신규 매장 온보딩 자동화, 환경 분리·롤백 지원
    2. 운영성 자동 추적 대시보드 — 매장별·시스템 모듈별 KPI 실시간 시각화
    3. 사업화 지표 자동 집계 시스템 — 매출·재방문·발송 ROI 자동 산출
    4. 장애 대응·롤백 시스템 — 실증 기간 중 시스템 장애 발생 시 자동 롤백·복구
