## 1. Executive Summary

### 1.1 핵심 요약

**단골이는 동네 정육점 사장님이 *머릿속에만 가지고 있던* 단골 정보를 *앱 하나*로 디지털화해, *재방문 매출을 자동으로 회수*하게 돕는 모바일 SaaS입니다.**

국내 정육점 약 *1.5만 곳* 사장님은 매장당 *300~500명* 단골을 보유하고 있지만, *얼굴 기억하는 수십 명* 외에는 *이탈해도 모르는 채* 잃고 있습니다. 단골이는 (1) *POS·카드 영수증 사진 한 장*으로 단골 명단을 자동 적재하고, (2) *AI가 추천하는 적정 시점·메시지*로 알림톡을 한 번에 발송하며, (3) *재방문 ROI를 사장님이 직접 확인*하는 구조로, 동네 정육점에서 *기존엔 불가능했던 1:1 단골 마케팅*을 가능하게 합니다.

알림톡 단가 폭락 *(건당 30원 → 7원)*, LLM 기반 자동화 비용 폭락, 정육점 2세대(30·40대) 디지털 사장님 진입 — 세 변화가 *동시에* 갖춰진 *2025~2026년*이 시장 진입의 변곡점입니다.

초기 1년은 *마장동·강남* 정육점 *50~100매장 베타*로 PMF 검증, 18개월 시점에 *수도권 1,000매장 / MRR 4.5억* 도달 → Series A 도전을 목표로 합니다. 이를 위해 시드 라운드 *12억원*을 조달하며, *60%*를 핵심 인력 5명 채용에 투입합니다.

## 2. 문제 정의 (Problem)

### 2.1 해결하려는 문제

동네 정육점 사장님은 *단골을 잃는 줄도 모른 채* 잃고 있습니다. 이는 *세 가지 구조적 부재* 때문입니다.

**① 단골 정보가 *사장님 머릿속*에만 있다**
한 매장 평균 단골 300~500명 *(가설, 인터뷰 검증 필요)*. 사장님이 *얼굴과 구매 패턴을 기억하는* 단골은 약 30명. 나머지 90%는 *6개월 안 와도 사라진 줄을 모름*. 종이 장부·카톡 채널·POS 단편 데이터에 *분산*되어 있어 *통합 조회 불가*.

**② 명절·기념일 알림 채널이 *없다***
정육점은 *추석·설·각종 기념일*에 매출이 *평소의 3~5배*. 단골에게 *1주 전 알림 한 번*이면 한우 선물세트 매출이 *수배* 차이. 그러나 *발송 채널 부재* — 매대 앞 *종이 안내문*이 전부.

**③ 재방문 동기를 만들 *도구가 없다***
대형 정육 브랜드는 *등급별 멤버십 할인*, 백화점은 *VIP 관리*. 동네 정육점은 *"10년 단골과 처음 온 손님의 가격이 동일"* — *이탈 방어 수단 0*. 사장님이 *호의·정*에 의존해 단골을 유지하는 *비공식 운영*에 머물러 있음.

### 2.2 기존 해결 방식의 한계

| 기존 방식 | 한계 |
|-----------|------|
| 종이 장부 | 검색·통계 불가, 분실·소실 위험 |
| 카톡 채널 | 알림 발송은 되지만 *고객·구매 데이터 분리* |
| 종합 POS의 단골 모듈 | 단말 교체 비용 300~500만원, 정육 특화 부재 |
| 본사 가맹형 (백화점·축산기업) | 동네 자영업 정육점이 가맹 진입 불가 |
| 사장님 머릿속 기억 | 30명 수준 — *진짜 시장(300~500명)*의 *10% 미만* |

→ *진입 비용 낮음 + 정육 특화 + 사장님 직접 사용* 의 *교집합*이 *시장에 없음*. 이 공백이 단골이의 자리입니다.

## 3. 솔루션 (Solution)

### 3.1 제품/서비스 개요

**단골이는 정육점 사장님이 *카운터에서 5분 안에* 단골 관리를 시작할 수 있는 모바일 앱입니다.** POS 교체나 별도 단말이 필요 없으며, *카드 결제 단말 영수증을 사진 한 장* 찍는 것만으로 단골 명단이 자동 누적됩니다.

### 3.2 사용자 여정 (사장님 입장)

1. **앱 다운로드** — 매장 카운터에서 사장님 스마트폰에 설치 (5분)
2. **첫 영수증 사진** — AI가 *고객 카드정보·금액·구매 부분육*을 자동 추출, 단골 DB 생성
3. **3주 누적 후 패턴 확인** — *재방문 주기, 평균 객단가, 선호 부위*가 자동 분석되어 대시보드에 노출
4. **AI 알림 추천** — *"이번 주 챙겨야 할 단골 N명"* + *"추천 메시지"* 푸시
5. **한 번 탭으로 알림톡 발송** — 메시지 검토 후 *보내기 한 번*
6. **ROI 추적** — 발송 후 *재방문 N명·매출 N원* 자동 트래킹

### 3.3 핵심 기능

| 기능 | 설명 | 차별점 |
|------|------|--------|
| 영수증 OCR 자동 단골 등록 | 카드 결제 영수증 사진 → 단골 DB 자동 적재 | POS 교체 불필요, 기존 결제 흐름 유지 |
| 단골 패턴 AI 분석 | 재방문 주기·객단가·선호 부위·이탈 위험도 | 정육 특화 (부분육 단가·신선도 패턴 학습) |
| 알림톡 발송 추천 | "지금 보낼 단골" + "추천 메시지" 자동 제안 | 사장님은 *검토·발송* 2번 탭만 |
| 재방문 ROI 대시보드 | 발송 → 재방문 → 매출 자동 트래킹 | 사장님이 *효과를 직접 확인* → 락인 강화 |
| (Phase 2) POS·카드사 연동 | 결제 데이터 자동 연동 | 영수증 사진 단계 제거 |

### 3.4 기술 스택

- **모바일**: React Native (iOS·Android 단일 코드베이스)
- **OCR / 데이터 추출**: 자체 미세조정 OCR 모델 + LLM 후처리 *(영수증 한국어 특화)*
- **추천 엔진**: 단골 행동 시계열 분석 + LLM 메시지 생성
- **알림 발송 인프라**: 카카오 알림톡 · LMS · 이메일 다채널
- **백엔드**: Python/FastAPI + PostgreSQL + Redis
- **장기 (Phase 2)**: POS·카드사 API 연동, 데이터 라이선스 사업화

### 3.5 제품 로드맵

| 시기 | 마일스톤 | 주요 기능 |
|------|---------|----------|
| 0~3개월 | 베타 출시 | 영수증 OCR, 기본 단골 DB, 수동 알림 발송 |
| 4~6개월 | 유료 전환 | AI 알림 추천, 발송 ROI 대시보드, 가격 정책 적용 |
| 7~12개월 | 다채널 확장 | LMS·이메일 추가, 매장 그룹 분석, B2B 영업 기능 |
| 13~18개월 | POS 연동 | 주요 정육 POS사·카드사 API 통합, 데이터 라이선스 시범 |

### 4.4 시장 트렌드 (Why Now)

세 변화가 동시에 변곡점을 만들고 있습니다.

1. **알림톡 단가 폭락** — 2020년 건당 ~30원 → 2025년 ~7원. *동네 매장도 ROI 성립*.
2. **사장님 세대 교체** — 부모 가게를 이어받은 30·40대 사장님 진입. *디지털 도구에 *적극적*이나 통합 도구 부재*.
3. **LLM 자동화 비용 폭락** — *1인 매장도* CRM 자동화 ROI 성립. 매장당 운영비 *월 N백원* 수준.

→ *데이터를 모을 채널 (POS·영수증)·메시지를 보낼 채널 (알림톡)·자동화할 두뇌 (LLM)* 가 *처음으로* 동시에 갖춰진 시점.

## 5. 비즈니스 모델 (Business Model)

### 5.1 수익 모델

**월 구독 + 알림 발송 종량제 (이중 구조)** *(가격 전부 가설, 베타 검증 필요)*

| 구분 | 금액 | 설명 |
|------|------|------|
| Basic 구독 | 월 3만원 | 단골 DB, 영수증 OCR, 기본 대시보드 |
| Pro 구독 | 월 9만원 | AI 알림 추천, 다채널 발송, 분석 리포트 |
| 알림톡 발송 | 건당 15원 | 매입 단가 ~7~10원, 마진 약 50% |

**예상 ARPU (Pro 매장 기준)**: 월 약 **18만원**
*(구독 9만원 + 평균 발송 600건 × 15원 = 9만원 = 합산 18만원)*

**가격 산정 근거** *(가설)*: 베타 사장님 N명 가격 인터뷰 → "월 *15~25만원*이면 가입 의향" 응답 다수. *알바생 시급 2시간 분량*. *알림 1건 성공 = 회수 가능* 수준.

### 5.2 단위 경제학 (Unit Economics) *(가설)*

| 지표 | 목표 | 업계 우수 기준 |
|------|------|---------------|
| **CAC** (고객획득비용) | 9만원 | — |
| **LTV** (고객생애가치) | 약 260만원 | — |
| **LTV / CAC** | 약 29배 | 3배 이상 |
| **월 이탈율** (Churn) | 3% | SMB SaaS 평균 5~7% |
| **Gross Margin** | 80% | SaaS 전형 |
| **Payback Period** | 0.6개월 | <12개월 |

> ⚠️ LTV/CAC 29배는 *비현실적으로 좋은 가설치*. 실 베타 데이터 누적 후 *보수적 재산정* 예정. *Series A 시점에 *검증된 수치*로 갱신*.

### 5.3 성장 전략 (GTM)

**Phase 1 (0~6개월): *마장동·강남* 침투**
- 정육 협회·도매시장 *오프라인 직접 영업* (사장님 네트워크 확보)
- *베타 매장 = 광고판* — 옆 가게 추천이 가장 강한 영업
- *베타 무료 → 4개월 후 유료 전환*

**Phase 2 (7~12개월): *서울 전역 확장***
- *동네 단위 침투* — 한 동네에 침투 후 *골목 클러스터링*
- 인플루언서 정육점 사장님 *유튜브·인스타* 콘텐츠 협업
- 정육 도매 단가 데이터 *부가 콘텐츠*로 사장님 락인

**Phase 3 (13~18개월): *수도권·인접 카테고리***
- POS사 *연동 파트너십* (정육점 N개 매장 확보 후 *역제안*)
- 반찬가게·청과로 카테고리 확장 시범

## 6. 경쟁 분석 (Competition)

### 6.1 경쟁 환경

이 시장의 진짜 경쟁자는 *다른 정육 CRM이 아닌*, 사장님이 *지금 쓰고 있는 종이 장부·머릿속 기억·카톡 채널*입니다 — *No Action* 이 가장 강한 경쟁.

직접·간접·대체재로 구분:

| 카테고리 | 플레이어 | 우리 대비 |
|---------|---------|----------|
| **직접 경쟁** | (현재 정육 특화 CRM 부재) | 동네 정육점 대상 직접 경쟁 *없음* |
| **간접 경쟁** | 종합 POS 단골 모듈 (○○POS, 키오스크형) | 단말 교체 비용 / 정육 특화 부재 |
|  | 백화점·체인 정육 CRM | 동네 자영업 진입 불가 (가맹 구조) |
| **대체재** | 카톡 채널 + 엑셀 | 데이터 분산·소실, 자동화 없음 |
|  | 종이 장부 + 머릿속 기억 | 30명 수준 — 진짜 시장의 10% |

### 6.2 포지셔닝

### 6.3 경쟁 우위 / 해자

| 차별점 | 종류 | 시간 효과 |
|--------|------|----------|
| 영수증 사진 자동 OCR | 기능 차별 | 단기 (6~12개월 모방 가능) |
| 정육 부분육·단골 패턴 학습 데이터 | 데이터 해자 | 누적될수록 *격차 확대* |
| 사장님 *직접 가입* 모델 (POS 교체 불필요) | 구조 차별 | 장기 — 대기업이 단가 매력 부족으로 진입 어려움 |
| 동네 *클러스터 침투* + 추천 네트워크 | 네트워크 효과 | 일정 침투 후 *후발 영업 비용 폭증* |
| POS·카드사와의 *데이터 라이선스* 협상력 (Phase 2) | 후방 통합 | 매장 수가 곧 협상력 |

### 6.4 "왜 대기업이 못 하는가" (Q&A 대비)

- **단가 매력 부족** — 동네 매장 ARPU 18만원/월은 카카오·네이버·POS 대기업의 *영업 인건비 ROI 불성립*. 동네 매장 *직접 영업*은 그들의 효율 비즈니스 모델과 맞지 않음.
- **카테고리 깊이 부족** — 부분육 단가·신선도·정육 단골 패턴은 *정육 특화 학습 데이터* 없이 못 만듦. *우리는 이 카테고리에 *전부 베팅*, 그들은 *전 카테고리 평균* 추구*.
- **사장님의 *대기업 *불신***— 동네 사장님은 *카카오·네이버에 데이터 *주는 것에 *민감*. *작은 회사가 *동맹*처럼 들어가는 것*이 동네 정육점 침투에 유리.
