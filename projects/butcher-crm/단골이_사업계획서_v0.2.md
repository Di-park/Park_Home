## 1. Executive Summary

### 1.1 핵심 요약

**㈜위브원의 단골이는 동네 정육점 사장님을 위해 *고객 분석 → 마케팅 판단 → 실행 → 학습* 전 주기를 자동화하는 *자가학습형 AI 에이전트*입니다.**

국내 정육점 약 **57,000개소 (시장 약 2,200억원)**, 정육점 매출의 **70% 이상이 단골 기반 반복 구매**이지만, 사장님은 *고객관리를 기억에 의존*해 단골 이탈을 인지하지 못한 채 매출을 잃고 있습니다. 단골이는 (1) POS 거래 데이터로 **이탈예측 자가학습 모형** (선행연구 AUC 0.75 실측), (2) 품목·날씨·명절 등 다변량 **수요 신호 감지** (MAPE 25% 목표), (3) 정육 특화 4차수 프롬프트 + 판별기 **개인화 문자 자가정제** (오류율 10% 목표), (4) **Depth별 마케팅 반응** 자가학습, (5) **통합 의사결정 엔진** 실증 (추천 실행률 70% 목표) — 5단계 자가학습 루프로 매장 매출 **+15%**, 마케팅 비용 **-50%** 를 달성합니다.

AI 에이전트 시장 폭발(2026 76억$ → 2034 2,000억$), 국내 1인당 정육 소비 회복(54.6→62.9kg), 정부 소상공인 디지털 전환 정책(50만 명 바우처) — 세 흐름이 동시에 변곡점입니다.

**진행 상태**: 정육점 1개소 **실서비스 파일럿** 운영 중 (거래 51,000건 / 단골 1,258명 분석). 정부 디딤돌 R&D 과제 **2.668억 확보** (26.07~27.12). 협력사 **㈜더담우** (연 매출 1,000억 정육 유통사) 5개 점포 확보 + 영업망 지원. 18개월 후 누적 **366매장 / ARR 13억** 도달 → Series A 도전 목표.

이를 위해 *정부 R&D 외 GTM·정식 제품화 자금*으로 시드 라운드 **12억원** *(가설)* 조달을 제안합니다.

## 2. 문제 정의 (Problem)

### 2.1 해결하려는 문제

오프라인 소상공인은 AI 시대의 *디지털 격차* 한가운데 있습니다. 이는 *세 가지 구조적 부재* 때문입니다 *(디딤돌 §1)*.

**① 고객관리가 *사장님 기억*에 의존**
대기업·이커머스는 풍부한 데이터 기반 *개인화 마케팅*을 운영. 동네 정육점은 *사장님 기억*에 의존. 파일럿 매장 실데이터: 거래 51,000건 / 5회 이상 방문 단골 **2,100명** 중 사장님이 이름·구매 패턴을 인지하는 비율 극소수. 정육점 매출의 **70% 이상이 단골 기반**인데도 *단골 자체가 데이터로 존재하지 않음*.

**② 범용 CRM은 *사무직 세일즈 전제*로 설계**
현존 SaaS CRM은 영업사원이 콜·이메일·미팅으로 고객을 관리하는 모델 전제. 정육점의 *부위·용도·가구단위·계절·명절* 등 **5개 이상 도메인 축**을 동시 활용하는 개인화 컨텍스트를 반영하지 못함. (반대로 정육점은 카페·편의점 대비 *LLM 개인화 표현력이 압도적*).

**③ 마케팅 대행은 *비싸고 효과 측정 불가***
기존 문자 마케팅 대행은 *일괄 발송형*. 효과 측정·재방문 추적·개인화 부재. 디딤돌 §0 기대효과 기준 단골이의 자가학습 엔진 대비 비용 **2배 이상** → 본 솔루션 도입 시 마케팅비 **50% 절감** 목표.

### 2.2 기존 해결 방식의 한계

| 기존 방식 | 한계 |
|-----------|------|
| 종이 장부 | 검색·통계 불가, 분실·소실 위험 |
| 카톡 채널 | 알림 발송은 되지만 *고객·구매 데이터 분리* |
| 종합 POS의 단골 모듈 | 단말 교체 비용 300~500만원, 정육 특화 부재 |
| 본사 가맹형 (백화점·축산기업) | 동네 자영업 정육점이 가맹 진입 불가 |
| 사장님 머릿속 기억 | 30명 수준 — *진짜 시장(300~500명)*의 *10% 미만* |

→ *진입 비용 낮음 + 정육 특화 + 사장님 직접 사용* 의 *교집합*이 *시장에 없음*. 이 공백이 단골이의 자리입니다.

## 3. 솔루션 (Solution)

### 3.1 제품/서비스 개요

**단골이는 정육점 POS 데이터를 기반으로 *고객 분석 → 마케팅 판단 → 실행 → 학습* 전 주기를 자동화하는 자가학습형 AI 에이전트입니다.** 매장 사장님은 결과(이번 주 챙겨야 할 단골 / 추천 메시지 / 발송 효과)만 확인하면 되며, 시스템은 월 1회 자동 재학습으로 매장별·통합 정확도를 지속 개선합니다.

### 3.2 5단계 자가학습 루프 (디딤돌 §2)

| 단계 | 기능 | 알고리즘 / 모델 | 성능 목표 |
|------|------|----------------|----------|
| **1단계** | 고객 이탈 예측 | Random Forest (RF1 방문주기, RF2 객단가). 매장별 5개 + 통합 모형 1개 | **AUC 0.75 이상** (선행연구 실측 달성) / OOB 0.7 / F1 0.6 |
| **2단계** | 품목 수요 신호 감지 | 다변량(판매·날씨·계절·명절·고객 패턴) → 타겟 자동 추출 | **MAPE 25% 이하** |
| **3단계** | 개인화 문자 자가정제 | 4차수 프롬프트(P1~P4) + 한국어 특화 판별기 + α=0.05 통계검증 | **오류 표현율 10% 이하** (현재 38%) |
| **4단계** | Depth별 마케팅 반응 학습 | D1(공통)·D2(품목)·D3(완전 맞춤) within-person 36회 패널 회귀 | 이탈 4분위 × Depth 상호작용 |
| **5단계** | 통합 의사결정 엔진 | 1~4단계 통합 운영, 30매장 4개월 실증 | **추천 실행률 70% 이상** |

각 단계는 *틀림 감지 → 자가 재학습 → 추적 지표 비교* 자동 루프 운영 (예: 이탈예측은 라벨 재조정→재학습→AUC 변화 추적).

### 3.3 사용자 여정 (사장님 입장)

1. **POS 연동** — 매장 POS 데이터를 통한 거래·고객 정보 자동 수집 (스키마 자동 매핑·정제 95% 정확도 목표)
2. **이탈 위험 단골 자동 분류** — 매일 / 매주 *4분위(Q1 정상 ~ Q4 임박)* 자동 갱신
3. **AI 추천 메시지** — Depth별(D1/D2/D3) 정육 특화 개인화 문구 자동 생성
4. **한 번 탭으로 알림톡 발송** — 사장님은 검토 → 발송
5. **반응 자가학습** — 발송 후 재방문·매출 자동 추적 → 시스템이 *반응 데이터로 다음 추천 정확도 개선*

### 3.4 핵심 기능

| 기능 | 설명 | 차별점 |
|------|------|--------|
| POS 데이터 자동 매핑·정제 | 매장별 상이한 POS 스키마를 통합 분석 가능 형태로 자동 변환 | 정확도 95% 목표 (디딤돌 §2 1차 지표) |
| 자가학습 이탈 예측 | 매장별·통합 RF 모형이 *월 1회 자동 재학습* | AUC 0.75 실측 (선행연구) |
| 정육 특화 수요 신호 | 부위·계절·명절·날씨 다변량 통합 | MAPE 25% 목표 |
| 정육 특화 문자 자가정제 | 4차수 프롬프트 + 한국어 판별기 + 화이트리스트 자가 업데이트 | 오류율 10% 목표 (현재 38%) |
| Depth 큐레이션 | 이탈 분위별 *최적 개인화 Depth* 자동 선택 | within-person 실험 기반 |
| 통합 의사결정 엔진 | 1~4단계 통합 + 추천 실행률 자동 추적 | 추천 실행률 70% 목표 |

### 3.5 기술 스택

- **AI/ML**: Random Forest (이탈예측), 다변량 회귀 (수요신호), LLM (메시지 생성) + G-Eval·한국어 특화 판별기
- **인프라**: AWS, LLM API (OpenAI/Claude), SMS/LMS 발송
- **데이터**: POS 거래 데이터 + 외부(날씨·명절) 변수 통합 파이프라인
- **검증**: TTA 시험인증 4건 예정 (27.12, 5개 성능지표 외부 검증)

### 6.4 "왜 대기업이 못 하는가" (Q&A 대비)

- **단가 매력 부족** — 동네 매장 ARPU 18만원/월은 카카오·네이버·POS 대기업의 *영업 인건비 ROI 불성립*. 동네 매장 *직접 영업*은 그들의 효율 비즈니스 모델과 맞지 않음.
- **카테고리 깊이 부족** — 부분육 단가·신선도·정육 단골 패턴은 *정육 특화 학습 데이터* 없이 못 만듦. *우리는 이 카테고리에 *전부 베팅*, 그들은 *전 카테고리 평균* 추구*.
- **사장님의 *대기업 *불신***— 동네 사장님은 *카카오·네이버에 데이터 *주는 것에 *민감*. *작은 회사가 *동맹*처럼 들어가는 것*이 동네 정육점 침투에 유리.
