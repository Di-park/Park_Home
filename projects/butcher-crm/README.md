**한 줄 정의**
> 자가학습형 AI 에이전트로 정육점 사장님의 *고객 분석 → 마케팅 판단 → 실행 → 학습* 전 주기 자동화 — 매장 매출 +15% / 마케팅비 -50% 목표

**회사**: ㈜위브원 | **대표**: 안동철
**투자 라운드**: Pre-Seed / Seed

## 두 문서의 관계

- **IR 덱** — 발표용 *압축* 자료 (슬라이드 1장 = 메시지 1개, 13장)
- **사업계획서** — 송부용 *상세* 자료 (10섹션 + 부록)
- 두 문서는 *동일한 사실 기반*. 한쪽을 갱신하면 *반드시 다른 쪽도 동기화*.
