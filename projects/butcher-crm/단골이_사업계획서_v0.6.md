## 1. Executive Summary

### 1.1 핵심 요약

**㈜위브원의 단골이는 *정육점 사장님이 손가락 하나 까딱하지 않아도* 단골이 관리되는, **정육점 특화 Zero-Task AI 에이전트** 입니다.** 토스포스·캐시노트가 자영업 *수평* 카테고리(결제·장부·일반 CRM)를 점유하는 동안, 우리는 *정육 수직 카테고리*(부분육·계절·명절·가구단위)를 *Zero-Task UX*로 끝까지 파는 회사입니다.

국내 정육점 약 **57,000개소 (시장 약 2,200억원)**, 정육점 매출의 **70% 이상이 단골 기반 반복 구매** *(파일럿 매장 거래 데이터 기반)* 이지만, 사장님은 *고객관리를 기억에 의존*해 단골 이탈을 인지하지 못한 채 매출을 잃고 있습니다. 단골이는 (1) *POS 거래만 들어오면* 단골 명단·구매 이력이 자동 누적, (2) *이번 주 챙겨야 할 단골*을 AI가 골라 사장님에게 푸시, (3) *정육점 말투의 개인화 메시지*를 자동 생성해 한 번 탭으로 알림톡 발송, (4) *재방문·매출 자동 트래킹* — 사장님 시간 5분으로 *기존엔 불가능했던 1:1 단골 마케팅*을 가능하게 합니다.

**제품 가치 가설**: 매장 매출 **+15%** / 마케팅비 **-50%**. *현 시점 실증 데이터 없음 — 시드 1차 6개월 마일스톤이 이 측정 자체*입니다.

AI 에이전트 시장 폭발(2026 76억$ → 2034 2,000억$), 국내 1인당 정육 소비 회복(54.6→62.9kg), 정부 소상공인 디지털 전환 정책(50만 명 바우처) — 세 흐름이 동시에 변곡점입니다.

**진행 상태**: 정육점 **1개소 파일럿 도입** — 단골 자동 분류 / 메시지 생성 / 문자 발송 *워크플로 가동 중* (누적 거래 약 5만 건 / 단골 약 2,100명). *도입 전/후 매출 효과는 측정 시작 전*. 협력사 **㈜더담우** (연 매출 1,000억 정육 유통사) — *5개 점포 영업망 협력 합의*, **도입은 시드 후 6개월 내 순차 시작 예정**. 18개월 후 누적 **366매장 / ARR 13억** *(가설)* 도달 → Series A 도전 목표.

이를 위해 시드 라운드 **12억원** *(가설)* 조달을 제안합니다.

## 2. 문제 정의 (Problem)

### 2.1 해결하려는 문제

동네 정육점 사장님은 *단골을 잃는 줄도 모른 채* 잃고 있습니다. 이는 *세 가지 구조적 부재* 때문입니다.

**① 단골 정보가 *사장님 머릿속*에만 있다**
파일럿 매장 한 곳만 봐도 *5회 이상 방문 단골이 약 2,100명*. 사장님이 이름·구매 패턴을 인지하는 비율은 극소수. 정육점 매출의 **70% 이상이 단골 기반**인데도 *단골 자체가 데이터로 존재하지 않음*. 종이 장부·카톡 채널·POS 단편 데이터에 *분산*되어 *통합 조회 불가*.

**② 명절·기념일 알림 채널이 *없다***
정육점은 *추석·설·각종 기념일*에 매출이 *평소의 3~5배*. 단골에게 *1주 전 알림 한 번*이면 한우 선물세트 매출이 *수배* 차이. 그러나 *발송 채널 부재* — 매대 앞 *종이 안내문*이 전부.

**③ 마케팅 대행은 *비싸고 효과 측정 불가***
기존 문자 마케팅 대행은 *일괄 발송형*. 효과 측정·재방문 추적·개인화 부재. 단골이 대비 *비용 2배 이상* — 본 솔루션 도입 시 마케팅비 **50% 절감** 목표 *(가설)*.

### 2.2 기존 해결 방식의 한계

| 기존 방식 | 한계 |
|-----------|------|
| 종이 장부 | 검색·통계 불가, 분실·소실 위험 |
| 카톡 채널 | 알림 발송은 되지만 *고객·구매 데이터 분리* |
| 종합 POS의 단골 모듈 | 단말 교체 비용 300~500만원, 정육 특화 부재 |
| 본사 가맹형 (백화점·축산기업) | 동네 자영업 정육점이 가맹 진입 불가 |
| 사장님 머릿속 기억 | 30명 수준 — *진짜 시장(300~500명)*의 *10% 미만* |

→ *진입 비용 낮음 + 정육 특화 + 사장님 직접 사용* 의 *교집합*이 *시장에 없음*. 이 공백이 단골이의 자리입니다.

## 3. 솔루션 (Solution)

### 3.1 제품/서비스 개요

**단골이는 정육점 사장님의 *행동 횟수 = 0* 을 목표하는 *Zero-Task AI 에이전트*입니다.** POS 거래만 들어오면 AI가 *단골 분류 → 메시지 작성 → 발송 → 효과 측정* 까지 자동으로 수행하며, 사장님은 *주 1회 5초* 리포트만 확인합니다.

### 3.2 Zero-Task 작동 방식 (사장님 행동 = 0)

1. **앱 다운로드 + POS 연동 (5분, 1회성)** — 매장 카운터에서 설치·연결, *발송 정책 사전 설정* (안전 가드레일)
2. **단골 명단 자동 누적** — POS 거래가 들어올 때마다 고객·구매 부분육·금액이 자동 분류 *(사장님 행동 0)*
3. **AI가 이번 주 챙길 단골 자동 선정** — 사장님은 보지도 않음 *(사장님 행동 0)*
4. **정육점 말투 개인화 메시지 자동 작성·발송** — *사장님 검토 단계 없음* *(사장님 행동 0)*
5. **재방문·매출 자동 추적 → 주간 리포트 1장** — 사장님은 *주 1회 5초* 만 확인 *(사장님 행동 = 1주 5초)*

→ **사장님 행동 부담 = 1주에 5초**. 토스포스·캐시노트 등 *수평 도구의 *사장님 매번 작업 필요* 모델*과 정반대.

### 3.3 핵심 기능 (가설)

| 기능 | 설명 | Zero-Task / 정육 특화 |
|------|------|---------------------|
| POS 자동 단골 등록 | POS 거래 → 단골 DB 자동 적재 | Zero-Task / 기존 결제 흐름 유지 |
| AI 단골 자동 선정 | 매주 챙길 단골을 시스템이 자동 결정 (사장님 검토 없음) | **Zero-Task** |
| 정육점 말투 메시지 *자동 작성·발송* | 부위·용도·이름·관계 톤 매핑 + 안전 가드레일 | **Zero-Task / 정육 특화** |
| 발송 정책 사전 설정 | 사장님이 *1회 설정* → 이후 시스템 자동 발송 | Zero-Task 안전망 |
| 주간 리포트 자동 생성 | "이번 주 N명 발송 / M명 재방문 / ₩L 매출" 1장 | Zero-Task (사장님 주 1회 5초) |
| 수동 개입 모드 (옵션) | 특별 단골은 사장님이 직접 메시지 작성 가능 | 신뢰 단계별 사장님 통제권 |
| 데이터 누적 효과 | 정육 도메인 데이터 + 발송 안전망 운영 시간 누적 | 후발 모방 난이도 ↑ |

### 3.4 기술 스택 개요

- **모바일**: React Native (iOS·Android 단일 코드베이스)
- **추천 엔진**: 단골 행동 시계열 분석 + LLM 메시지 생성
- **알림 발송 인프라**: 카카오 알림톡 · LMS · 이메일 다채널
- **백엔드**: Python/FastAPI + PostgreSQL + Redis
- **장기**: POS·카드사 API 연동, 데이터 라이선스 사업화

### 3.5 제품 로드맵

| 시기 | 마일스톤 | 주요 기능 |
|------|---------|----------|
| 0~3개월 | 베타 출시 | POS 연동, 단골 DB, 수동 알림 발송 |

| 13~18개월 | POS 연동 확장 | 주요 정육 POS사·카드사 API 통합, 데이터 라이선스 시범 |

### 4.4 시장 트렌드 (Why Now)

**수평 SaaS 점유 → *수직 특화 윈도우* 가 열린 시점.**

1. **수평 자영업 SaaS의 카테고리 점유 완료** — 토스포스·캐시노트가 결제·장부·일반 CRM을 *전 자영업 공통*으로 깔고 있음. *수평 카테고리는 이미 닫힘*. 남은 큰 기회는 *수직 카테고리* — *한 업종에 깊게 들어가서 도메인 데이터·UX로 차별화*하는 회사.
2. **AI 에이전트 기술 성숙** — 머신러닝 이탈/수요 예측 + LLM 개인화 텍스트가 *실용 수준* 도달. *수직 도메인 학습 데이터*를 가진 회사가 *Zero-Task 자동화*를 처음 만들 수 있는 시점.
3. **정육 소비 회복** — 1인당 연 정육 소비 +15% (5년) 성장. 신규 매장 대비 *기존 매장 단골 ROI* 상승.
4. **정부 디지털 전환 정책** — 소상공인 바우처 사업이 *AI SaaS 매칭 채널*로 직접 작동.

→ *수평 SaaS 점유 완료 · AI 에이전트 성숙 · 정육 시장 회복 · 정부 보조* 가 동시에 갖춰진 첫 시점.

## 5. 비즈니스 모델 (Business Model)

### 5.1 수익 모델

**월 정액 SaaS + 문자 건당 과금**

| 구분 | 금액 | 설명 |
|------|------|------|
| Basic 구독 | 월 **33,000원** | AI 단골관리 전 기능 |
| 문자 발송 | 건당 **33원** | 매입가 대비 마진 포함 |

**예상 ARPU (매장 월)**: 약 **8~12만원** *(가설)*
*(구독 33,000원 + 문자 평균 1,500~2,500건 × 33원)*

**가격 산정 근거**: 베타 사장님 가격 인터뷰 기반. *알바생 시급 1~2시간 분량* 으로 정육점 사장님 부담 수준 검증.

**기대 효과 (제품 가치 가설 — 실증 데이터 없음)**
- 매장 매출 평균 **+15%** *(목표치, 베타에서 측정 예정)*
- 마케팅비 **-50% 이상** *(목표치, 기존 문자 마케팅 대행 대비)*

## 6. 경쟁 분석 (Competition)

### 6.1 경쟁 환경 — 수평 점유 SaaS의 *빈자리*

자영업 SaaS 시장은 *수평 카테고리*(전 업종 공통 결제·장부·일반 CRM)와 *수직 카테고리*(특정 업종 깊이) 로 갈라집니다. **수평은 이미 토스포스·캐시노트가 점유 중**입니다. *정육 특화* 와 *Zero-Task UX* 두 축의 교집합 — 즉 *수직 × Zero-Task* 사분면은 *비어 있습니다*.

```
   Zero-Task (사장님 손 = 0)
                  ●
                  │  [단골이]                  ← 우리가 노리는 빈자리
                  │  (정육 특화 AI 에이전트)
                  │
                  │  토스포스 CRM 모듈
                  │  캐시노트 단골 알림
                  │  카카오 알림톡 (수동)
                  │
                  │  카톡 채널 + 엑셀
                  │  종이 장부
                  │___________________________
   High-Task                      수직(정육 특화) →
```

### 6.2 경쟁 카테고리 매핑

| 플레이어 | 카테고리 | 정육 특화 | Zero-Task | 우리 대비 |
|---------|---------|----------|-----------|----------|
| **단골이 (㈜위브원)** | *수직 + Zero-Task* | ✅ | ✅ | — |
| **토스포스** (CRM 모듈) | 수평 자영업 | ❌ | △ (자동화 시작) | *정육 도메인 부재* / 부위·명절 표현력 0 |
| **캐시노트** (단골 알림) | 수평 자영업 | ❌ | △ | 일괄 발송 위주 / 사장님 작업 필요 |
| 카카오 알림톡 (직접 운영) | 수평 채널 | ❌ | ❌ | 사장님이 매번 작성·발송 — Zero-Task 아님 |
| 종합 POS 단골 모듈 | 수평 결제 | ❌ | ❌ | 단말 교체 비용 / 정육 특화 부재 |
| 백화점·체인 정육 CRM | 수직 정육 | ✅ | △ | 동네 자영업 진입 불가 (가맹 구조) |
| 카톡 채널 + 엑셀 | 수평 채널 | ❌ | ❌ | 분산·소실 / 자동화 없음 |
| 종이 장부 + 머릿속 | — | — | ❌ | 30명 수준 — 진짜 시장의 10% |

### 6.3 경쟁 우위 / 해자

| 차별점 | 종류 | 시간 효과 |
|--------|------|----------|
| 정육 도메인 학습 데이터 (부분육·계절·명절·가구단위) | 데이터 해자 | 누적될수록 *격차 확대* |
| Zero-Task UX 신뢰 자산 (발송 정책·안전 가드레일·예외 케이스) | 운영 해자 | 데이터 + 운영 시간이 둘 다 모이는 회사만 가능 |
| 사장님 *직접 가입* (POS 교체 불필요) | 구조 차별 | 수평 SaaS의 단가 ROI 불성립 |
| 동네 클러스터 침투 + 사장님 추천 네트워크 | 네트워크 효과 | 일정 침투 후 *후발 영업 비용 폭증* |
| POS·카드사 데이터 라이선스 협상력 | 후방 통합 | 매장 수가 곧 협상력 |

### 6.4 "왜 토스포스·캐시노트가 못 하는가" (Q&A 대비)

- **수평 비즈니스 모델 구조** — 그들의 ROI는 *전 자영업 공통* 기능에서 나옴. 정육 *5개 도메인 축* 학습 데이터를 *그들의 인력·예산 우선순위*에 넣는 일은 없음. (식당·카페·미용실의 *N배*가 정육보다 크기 때문)
- **Zero-Task UX 책임 한계** — 수평 SaaS는 *사장님에게 최종 발송 버튼*을 맡기는 구조에서 못 벗어남. *업종별 안전 가드레일* 누적이 *전 업종 동시*로는 불가능. 우리는 *정육에만 Zero-Task 책임을 짐*.
- **공존 가능성** — 같은 정육 매장에서 *단골이 + 토스포스/캐시노트* 가 *공존*할 수 있음 (결제·장부는 그들, 단골 마케팅 자동화는 우리). 즉 경쟁이 아닌 *수평+수직 분업*.

### 6.5 "왜 대기업(카카오·네이버)이 못 하는가"

- **단가 매력 부족** — 동네 매장 ARPU 약 10만원/월은 카카오·네이버 대기업의 *영업 인건비 ROI 불성립*.
- **카테고리 깊이 부족** — 부분육 단가·신선도·정육 단골 패턴은 *정육 특화 학습 데이터* 없이 못 만듦.
- **사장님의 대기업 데이터 불신** — 동네 사장님은 *카카오·네이버에 데이터 *주는 것에 민감*. 작은 회사가 *수직 카테고리 동맹*으로 들어가는 것이 침투에 유리.
