**토스플레이스도, 캐시노트도 *정육점*은 못 뚫었습니다.**

- 자영업 전반엔 빠르게 침투한 거대 SaaS들이, *유독 정육점에서는* 점유율이 없습니다.
- 베타 매장 사장님 **전원이 "그런 거 바꿔본 적 없다"** *(현장 인터뷰)*.

> **질문은 두 가지입니다.**

*이 덱은 이 두 질문에 답합니다.*

## 슬라이드 3. 왜 못 뚫었나 — 정육 시장의 구조 = 우리의 해자

**정육은 *다른 자영업과 다르게 움직이는* 시장입니다. 그래서 범용 SaaS가 못 들어옵니다.**

### 01. 정육 시장의 비정형성
- 판매자(사장님) *협상력이 높고*, 거래가 *비정형적* (부분육·가구단위·명절·단골 외상)
- 범용 POS·CRM의 *표준화된 기능*으로는 이 도메인을 담지 못함

### 02. 사장님의 보수적 충성도
- *"잘 되면 안 바꾼다."* 한 번 안착한 방식을 몇 년 그대로 유지
- 신규 도구 진입 장벽이 매우 높음

### 03. 경쟁사의 *구조적* 한계 (못 하는 게 아니라 안 하는 것)
- 토스·캐시노트의 ROI는 *전 자영업 공통* 기능에서 나옴 → 정육 *5개 도메인 축* 학습을 인력·예산 우선순위에 넣을 이유가 없음
- 식당·카페·미용실 시장이 정육의 *N배* → 정육은 영원히 후순위

> **그래서 이 시장은 비어 있습니다. 진입 장벽이 높다 = *먼저 들어간 회사에게 시간을 벌어주는 해자*.**

```
   Zero-Task (사장님 손 = 0)
        ↑
        │                          ★ 또와 (정육 100% × Zero-Task)
        │  토스플레이스 ●
        │  캐시노트 ●          ● 정육점 SYSTEM 대리점
   High-Task ──────────────────────────────→
        수평 (전 자영업)        수직 (정육 특화)
```

## 슬라이드 4. Problem — 사장님의 3중 부재

**정육점 매출의 *70%*는 단골에게서. — 그런데 사장님은 단골을 *잃는 줄도 모른 채* 잃고 있습니다.**

**01. 단골 정보가 사장님 머릿속에만 있다**
파일럿 1매장만 봐도 단골 약 2,100명. 사장님이 이름·패턴을 인지하는 단골은 극소수.

**02. 단골이 떠나기 전 어떠한 신호도 알 수 없다**
방문 주기가 늘어나도, 객단가가 떨어져도 사장님은 모른다. 다른 가게로 옮긴 후에야 알아챈다.

**03. 단골을 관리할 수 있는 여유가 없다**
아침부터 저녁까지 장사 준비·손질·응대·마감까지 다 해야 하는 사장님에겐, 체계적으로 고객을 관리할 *시간적·비용적 여유*가 부족.

## 슬라이드 5. 수요 가설 — 왜 우리는 "수요가 있다"고 믿는가 ⭐ *(NEW)*

> **"정육점에서 고기 사는데 CRM이 필요한가?" — 투자자의 가장 근원적인 질문에 정면으로 답합니다.**

**우리는 *없는 수요를 만들려는* 게 아니라, *이미 존재하지만 도구가 없는 수요*를 봅니다.**

### 정황 근거 (Why we believe)

| | 근거 | 시사점 |
|---|------|--------|
| **①** | 정육점 매출의 *70%가 단골 반복구매* (파일럿 데이터) | 단골 = 매출의 본체. 관리 가치가 구조적으로 큼 |
| **②** | 명절·기념일 매출이 *평소의 3~5배* | *타이밍 마케팅* 여지가 압도적 |
| **③** | 사장님은 *이미* 단골을 챙기려 시도 중 — 전화·외상장부·기억 | *잠재 수요는 있으나 도구가 없음* (latent demand) |
| **④** | 사장님 인터뷰: *"단골 알면 매출 다른데, 하루 100명 보면 다 잊어버린다"* | 의지는 있으나 *물리적으로 불가능* → 자동화가 유일한 해 |

### 정직한 고백 — 그리고 우리의 약속

- **아직 *정량 증거*(도입 전/후 매출)는 없습니다.** 이게 우리가 가장 자주 받는 지적이고, 우리도 압니다.
- 그래서 **이 Pre-Seed는 *제품을 만드는 돈*이 아니라 *수요를 숫자로 증명하는 돈*입니다.**
- **Stage 1 (6개월) 단일 미션**: 파일럿 매장 *도입 전/후 매출*로 "수요가 있다"를 증명. 실패하면 *제품 PIVOT*.

> *투자자께 드리는 약속: 6개월 뒤, 우리는 가설이 아니라 숫자를 들고 옵니다.*

## 슬라이드 6. Solution

> **사장님은 *눈앞의 손님*에게 집중하세요. 나머지는 또와가 알아서 합니다.**

**효과 (제품 가치 가설 — Stage 1에서 실증 예정)**

| | 효과 |
|---|---|
| **주 5초** | 시간 절약 (사장님이 단골관리에 쓰는 시간) |
| **−50%** | 비용 감소 (마케팅·재고 비용) |
| **+15%** | 매출 증가 (매장 매출) |

**기능 — 3축**
- **① 매장 데이터 기반 단골 관리** (Wedge) — POS 거래 → 단골 자동 분류·메시지·발송·재방문 추적
- **② 재고량 분석 CRM 활동** — 과재고 부위 자동 마케팅·신선도 기반 추천
- **③ 판매량 예측 기반 발주 제안·자동화** — 단골 패턴 + 명절·계절 변수 → 발주량 자동

*효과 수치는 제품 가치 가설 — 실증 데이터 없음, 베타 30매장에서 측정 예정.*

## 슬라이드 11. Business Model — 단계적 전략 ⭐ *(전면 재작성 / F4·F11·F12)*

> **"CRM으로 침투해 납품으로 갈 것인가, 마케팅 수수료를 취할 것인가?" — 우리는 *단계적으로 둘 다*, 단 *순서가 명확*합니다.**

### 단계적 전략 (지금 라운드가 어디인지 명확히)

| | **1단계 (지금 — Pre-Seed)** | **2단계 (Series A 후)** |
|---|---|---|
| 정체성 | **정육 마케팅·CRM SaaS** | **정육 유통 중개 플랫폼** |
| 수익 | 구독 + 문자 + 마케팅 효과 | 유통 매입·중개 수수료 |
| 우리가 파는 것 | **소프트웨어만** (하드웨어 X) | 유통·물류 (검증 후 진입) |
| 검증 미션 | 수요·공헌이익 양수 | 유통 GMV·중개 마진 |

> **지금 라운드는 *1단계*입니다.** 저울·납품·물류 디지털화는 *수요가 증명된 후* 2단계에서. → *지금 팀이 감당 못 할 일을 약속하지 않습니다.* *(F11 정면 대응)*

### 점주 수익 영향 — 구독료는 회수되는가? *(F4)*

> 구독 33,000원/월이 점주에게 *어떻게 회수되는지* 단위경제로 (가정 기반 시뮬레이션).

| 항목 | 값 (가정) |
|------|----------|
| 정육 객단가 | 약 25,000원 |
| 정육 마진율 | 약 25% → 회당 마진 **6,250원** |
| 구독료 회수점 | 33,000 ÷ 6,250 ≈ **단골 5~6명 추가 재방문/월** |
| 파일럿 단골 풀 | 2,100명 → *월 0.3%만 살려도* 구독료 회수 |

> **즉, 또와가 *단골 5~6명*의 재방문만 추가로 만들어도 구독료는 회수되고, 그 이상은 전부 점주 순증.** *(수치는 가정 — Stage 1에서 실측)*

### 수익 구조 (1단계)

| 수익원 | | Unit Economics (가설) |
|---|---|---|
| Basic 구독 | ₩33,000/월 | Gross Margin 75~80% |
| 문자 발송 | ₩33/건 | LTV/CAC 5배+ |
| 매장 ARPU | ₩8~12만/월 | 월 이탈율 3% |
