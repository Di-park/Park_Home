## 슬라이드 3. 문제 (Problem)

### 슬라이드 본문

**동네 정육점 사장님은 단골을 *잃는 줄도 모른 채* 잃고 있습니다.**

1. **단골 정보가 *사장님 머릿속*에만 있다**
   파일럿 매장 한 곳만 봐도 *단골 천여 명*. 사장님이 *이름·구매 패턴을 기억하는* 단골은 극소수. 나머지는 *몇 달 안 와도 사라진 줄 모름*.

2. **명절·기념일 알림 채널이 *없다***
   추석·설·기념일이 *연 매출의 절반*. 단골에게 *1주 전 알림* 한 번이면 한우 세트 매출이 *수배 차이*. 그런데 채널이 없어 *매대 앞 종이 안내*가 전부.

3. **재방문 동기를 만들 *도구가 없다***
   대형 정육 브랜드는 *등급 멤버십*, 백화점은 *VIP 관리*. 동네 정육점은 *"10년 단골과 처음 온 손님 가격이 동일"*. 이탈 방어 수단 0.

## 슬라이드 4. Why Now (시장 타이밍)

1. **수평 자영업 SaaS의 카테고리 점유 완료**
   *토스포스·캐시노트* 가 결제·장부·일반 CRM을 *전 자영업 공통*으로 깔고 있음. *수평 카테고리는 이미 닫힘*. 남은 큰 기회는 *수직 카테고리* — *한 업종에 깊게 들어가서 도메인 데이터·UX로 차별화*하는 회사.

2. **AI 에이전트 시장 폭발** — 2026 **76억 달러 → 2034 2,000억 달러** 전망
   머신러닝 이탈/수요 예측 + LLM 개인화 텍스트가 *실용 수준* 도달. *수직 도메인 학습 데이터*를 가진 회사가 *Zero-Task 자동화*를 처음 만들 수 있는 시점.

3. **국내 정육 소비 지속 성장** — 1인당 연 **54.6kg(2019) → 62.9kg(2024)** *(농촌경제연구원)*
   정육 시장 자체가 *성장 카테고리*. 1매장당 단골 관리 ROI 상승.

4. **정부 소상공인 디지털 전환 정책** — 50만 명 대상 연 *수천억원 바우처* 투입
   소상공인 AI 도입에 정부 보조가 매칭되는 시기 — 단골이는 *수직 특화 바우처 매칭 SaaS* 후보.

→ ***수평 SaaS 점유 완료 · AI 에이전트 성숙 · 정육 소비 회복 · 정부 보조*** 가 동시에 갖춰진 첫 시점.

## 슬라이드 5. 솔루션 (Solution)

### 슬라이드 본문

**사장님은 *결과만* 봅니다. AI가 *다 합니다*. — Zero-Task.**

```
기존 단골 마케팅 도구 ───→  사장님 손이 *여러 번* 필요
                              (분류 보기 → 추천 검토 → 메시지 수정 → 발송 → 효과 확인)

단골이 ──────────────→  사장님 손이 *0번* 필요 (Zero-Task)
                              AI 가 알아서 *분류 + 작성 + 발송 + 측정*
                              사장님은 매주 1번 *결과 리포트*만 확인
```

[📱 앱 스크린샷 — 디자인 작업 후 삽입]
- 화면 1: *주간 리포트 한 장* — "이번 주 N명에게 발송했고, M명이 돌아왔습니다 (+₩L)"
- 화면 2: 단골별 *상태 카드* (필요 시 사장님이 *볼 수 있는* 옵션)
- 화면 3: *수동 개입 모드* — 특별한 단골은 사장님이 직접 메시지 쓸 수 있음

**Zero-Task 작동 방식 (사장님 행동 = 0)**

1. **POS 거래만 들어오면** → AI가 단골 명단·구매 이력 자동 누적
2. **AI가 이번 주 챙길 단골 자동 선정** — 사장님은 보지도 않음
3. **정육점 말투 개인화 메시지 자동 작성·발송** — *사장님 검토 단계 없음* (안전장치: 사장님 사전 *발송 정책* 설정만)
4. **재방문·매출 자동 추적 → 주간 리포트 1장** — 사장님은 *주 1번 5초* 만 확인

**핵심 가치 가설**
- 사장님 *행동 횟수 0회/주* — 토스포스·캐시노트 등 *수평 도구의 작업 부담*과 정반대
- *POS 교체 불필요* — 기존 결제 흐름 그대로
- 정육 특화 데이터(부위·명절·가구단위) 누적으로 *시간이 갈수록 AI 정확도가 사장님 노동 없이* 올라감

### 메모
- "사장님이 *손도 안 댄다*" 가 핵심 카피 — 정육 사장님 인터뷰에서 *반복 검증*된 needs
- *완전 자동 발송* 의 신뢰 문제 → 발송 정책 *사전 설정* + *안전 가드레일*(부적절 표현 차단) 별도 슬라이드/문서로 보강 필요
- 데모 영상 30초 — *주간 리포트 화면* 중심으로 촬영

## 슬라이드 6. 제품·경쟁 (Product & Competition)

### 슬라이드 본문

**수평 점유 SaaS의 *빈자리* — *정육 특화 × Zero-Task* 사분면.**

```
  Zero-Task
  (사장님 손 = 0)
        ●           │  [단골이]                    ← 우리가 노리는 빈자리
                    │  (정육 특화 AI 에이전트)
                    │
                    │
                    │  토스포스 CRM 모듈
                    │  캐시노트 단골 알림
                    │  카카오 알림톡 (수동 운영)
                    │
   High-Task        │  카톡 채널 + 엑셀
   (사장님이 매번 작업)│  종이 장부
                    │___________________________
              수평(전 자영업)        수직(정육 특화) →
```

**경쟁 카테고리 매핑**

| 플레이어 | 카테고리 | 정육 특화 | Zero-Task | 우리 대비 |
|---------|---------|----------|-----------|----------|
| **단골이** | 수직 + Zero-Task | ✅ | ✅ | — |
| **토스포스** (CRM 모듈) | 수평 자영업 | ❌ | △ (자동화 시작) | *정육 도메인 부재* / *부위·명절 표현력 0* |
| **캐시노트** (단골 알림) | 수평 자영업 | ❌ | △ | *일괄 발송 위주* / 사장님 작업 필요 |
| 카카오 알림톡 (직접) | 수평 채널 | ❌ | ❌ | 수동 운영 — Zero-Task 아님 |
| 종합 POS 단골 모듈 | 수평 결제 | ❌ | ❌ | 단말 교체 비용 / 정육 특화 부재 |
| 백화점·체인 정육 CRM | 수직 정육 | ✅ | △ | *동네 자영업 진입 불가* (가맹 구조) |
| 종이 장부 + 머릿속 | — | — | ❌ | 30명 수준 (시장의 10%) |

**🛡️ 해자 — *수직 × Zero-Task* 의 시간 효과**

- **정육 도메인 학습 데이터** — 부분육·계절·명절·가구단위 등 5개 축의 *고객-품목 패턴*. 수평 SaaS가 *전 업종 평균*을 추구할 때 우리는 *정육에만* 데이터 누적. 시간이 갈수록 격차 확대.
- **Zero-Task UX 신뢰 자산** — 사장님이 *진짜로 손을 안 대도* 사고가 안 나려면 *발송 정책·안전 가드레일·예외 케이스*가 누적되어야 함. 데이터 + 운영 시간이 모두 모이는 회사만 가능.
- **사장님 네트워크 효과** — 옆 가게 추천이 가장 강한 영업.
- **POS 협상력** — 정육 매장 N개 확보 시 *카드사·POS사 데이터 연동 사업자*로 역제안 가능.

**🎯 왜 토스포스·캐시노트가 못 하는가**
- 그들의 비즈니스 모델 = *전 자영업 공통*. 정육 *5개 도메인 축* 학습은 *그들의 ROI에 맞지 않음*.
- *Zero-Task 발송*은 *업종별 안전 가드레일* 누적이 필요. 수평 SaaS는 사장님에게 *최종 발송 버튼*을 맡기는 구조에서 못 벗어남.
- 결과: 같은 정육 매장에 *단골이 + 토스포스/캐시노트* 가 *공존* 가능 (결제·장부는 그들, 단골 마케팅은 우리)

## 슬라이드 8. 비즈니스 모델 (Business Model)

### 슬라이드 본문

**사장님 매출이 늘면 → 단골이도 번다 (이해관계 정렬)**

**수익 모델: 월 정액 SaaS + 문자 건당 과금**

| 구분 | 금액 | 설명 |
|------|------|------|
| Basic 구독 | 월 **33,000원** | AI 단골관리 전체 기능 |
| 문자 발송 | 건당 **33원** | 매입가 대비 마진 포함 |

**예상 ARPU (월)**: 매장당 약 **8~12만원** *(가설)*
— 구독 33,000원 + 문자 평균 1,500~2,500건 × 33원

**기대효과 (제품 가치 가설 — 실증 데이터 없음, 베타에서 측정 예정)**

**Unit Economics** *(가설 — 베타 누적 후 갱신)*

| 지표 | 목표 *(가설)* | 업계 기준 |
|------|--------------|----------|

| LTV | 약 200만원 | (ARPU 10만 × 24개월 × 80% 마진) |
| **LTV/CAC** | **~25배** | SaaS 우수 3배+ |
| Payback | 1개월 미만 | SaaS 우수 <12개월 |
