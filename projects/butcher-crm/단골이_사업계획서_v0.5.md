## 1. Executive Summary

### 1.1 핵심 요약

**㈜위브원의 단골이는 동네 정육점 사장님이 *머릿속에만 가지고 있던 단골 정보*를 *앱 하나*로 디지털화해, *AI가 챙겨야 할 단골과 메시지를 자동으로 추천*하는 모바일 SaaS입니다.**

국내 정육점 약 **57,000개소 (시장 약 2,200억원)**, 정육점 매출의 **70% 이상이 단골 기반 반복 구매** *(파일럿 매장 거래 데이터 기반)* 이지만, 사장님은 *고객관리를 기억에 의존*해 단골 이탈을 인지하지 못한 채 매출을 잃고 있습니다. 단골이는 (1) *POS 거래만 들어오면* 단골 명단·구매 이력이 자동 누적, (2) *이번 주 챙겨야 할 단골*을 AI가 골라 사장님에게 푸시, (3) *정육점 말투의 개인화 메시지*를 자동 생성해 한 번 탭으로 알림톡 발송, (4) *재방문·매출 자동 트래킹* — 사장님 시간 5분으로 *기존엔 불가능했던 1:1 단골 마케팅*을 가능하게 합니다.

**제품 가치 가설**: 매장 매출 **+15%** / 마케팅비 **-50%**. *현 시점 실증 데이터 없음 — 시드 1차 6개월 마일스톤이 이 측정 자체*입니다.

AI 에이전트 시장 폭발(2026 76억$ → 2034 2,000억$), 국내 1인당 정육 소비 회복(54.6→62.9kg), 정부 소상공인 디지털 전환 정책(50만 명 바우처) — 세 흐름이 동시에 변곡점입니다.

**진행 상태**: 정육점 **1개소 파일럿 도입** — 단골 자동 분류 / 메시지 생성 / 문자 발송 *워크플로 가동 중* (누적 거래 약 5만 건 / 단골 약 2,100명). *도입 전/후 매출 효과는 측정 시작 전*. 협력사 **㈜더담우** (연 매출 1,000억 정육 유통사) — *5개 점포 영업망 협력 합의*, **도입은 시드 후 6개월 내 순차 시작 예정**. 18개월 후 누적 **366매장 / ARR 13억** *(가설)* 도달 → Series A 도전 목표.

이를 위해 시드 라운드 **12억원** *(가설)* 조달을 제안합니다.

## 2. 문제 정의 (Problem)

### 2.1 해결하려는 문제

동네 정육점 사장님은 *단골을 잃는 줄도 모른 채* 잃고 있습니다. 이는 *세 가지 구조적 부재* 때문입니다.

**① 단골 정보가 *사장님 머릿속*에만 있다**
파일럿 매장 한 곳만 봐도 *5회 이상 방문 단골이 약 2,100명*. 사장님이 이름·구매 패턴을 인지하는 비율은 극소수. 정육점 매출의 **70% 이상이 단골 기반**인데도 *단골 자체가 데이터로 존재하지 않음*. 종이 장부·카톡 채널·POS 단편 데이터에 *분산*되어 *통합 조회 불가*.

**② 명절·기념일 알림 채널이 *없다***
정육점은 *추석·설·각종 기념일*에 매출이 *평소의 3~5배*. 단골에게 *1주 전 알림 한 번*이면 한우 선물세트 매출이 *수배* 차이. 그러나 *발송 채널 부재* — 매대 앞 *종이 안내문*이 전부.

**③ 마케팅 대행은 *비싸고 효과 측정 불가***
기존 문자 마케팅 대행은 *일괄 발송형*. 효과 측정·재방문 추적·개인화 부재. 단골이 대비 *비용 2배 이상* — 본 솔루션 도입 시 마케팅비 **50% 절감** 목표 *(가설)*.

### 2.2 기존 해결 방식의 한계

| 기존 방식 | 한계 |
|-----------|------|
| 종이 장부 | 검색·통계 불가, 분실·소실 위험 |
| 카톡 채널 | 알림 발송은 되지만 *고객·구매 데이터 분리* |
| 종합 POS의 단골 모듈 | 단말 교체 비용 300~500만원, 정육 특화 부재 |
| 본사 가맹형 (백화점·축산기업) | 동네 자영업 정육점이 가맹 진입 불가 |
| 사장님 머릿속 기억 | 30명 수준 — *진짜 시장(300~500명)*의 *10% 미만* |

→ *진입 비용 낮음 + 정육 특화 + 사장님 직접 사용* 의 *교집합*이 *시장에 없음*. 이 공백이 단골이의 자리입니다.

## 3. 솔루션 (Solution)

### 3.1 제품/서비스 개요

**단골이는 정육점 사장님이 *카운터에서 5분 안에* 단골 관리를 시작할 수 있는 모바일 앱입니다.** POS 교체나 별도 단말이 필요 없으며, *POS 거래만 들어오면* 단골 명단·구매 이력이 자동 누적되고, *AI가 이번 주 챙겨야 할 단골과 메시지를 추천*합니다.

### 3.2 사용자 여정 (사장님 입장)

1. **앱 다운로드 + POS 연동** — 매장 카운터에서 5분 안에 설치·연결
2. **단골 명단 자동 누적** — POS 거래가 들어올 때마다 고객·구매 부분육·금액이 자동 분류
3. **이번 주 챙겨야 할 단골 푸시** — *떠날 것 같은 단골 / 명절 한우 추천 단골*을 AI가 매일·매주 골라 제안
4. **개인화 메시지 자동 생성** — 정육점 말투로 *부위·계절·명절*에 맞춘 문구 자동 작성
5. **한 번 탭으로 알림톡 발송** — 사장님은 *검토·발송* 2번 탭만
6. **재방문 ROI 자동 확인** — 발송 후 *재방문 N명·매출 N원*이 한 화면에

### 3.3 핵심 기능 (가설)

| 기능 | 설명 | 차별점 |
|------|------|--------|
| POS 자동 단골 등록 | POS 거래 → 단골 DB 자동 적재 | POS 교체 불필요, 기존 결제 흐름 유지 |
| 단골 상태 카드 | 마지막 방문·평균 객단가·선호 부위·이탈 위험도 | *사장님이 모르던 단골 패턴*을 1초에 노출 |
| AI 단골 추천 | "오늘 챙겨야 할 단골 N명" 자동 추출 | 정육 특화 (부위·계절·명절 가중치) |
| 정육점 말투 메시지 생성 | 부위·용도·이름·관계 톤 매핑 | 사장님은 *검토·발송* 2번 탭만 |
| 재방문 ROI 대시보드 | 발송 → 재방문 → 매출 자동 트래킹 | *효과를 사장님이 직접 확인* → 락인 |
| 데이터 누적 효과 | 시간이 갈수록 매장별 추천 정확도 개선 | 후발주자 모방 난이도 ↑ |

### 3.4 기술 스택 개요

- **모바일**: React Native (iOS·Android 단일 코드베이스)
- **추천 엔진**: 단골 행동 시계열 분석 + LLM 메시지 생성
- **알림 발송 인프라**: 카카오 알림톡 · LMS · 이메일 다채널
- **백엔드**: Python/FastAPI + PostgreSQL + Redis
- **장기**: POS·카드사 API 연동, 데이터 라이선스 사업화

### 3.5 제품 로드맵

| 시기 | 마일스톤 | 주요 기능 |
|------|---------|----------|
| 0~3개월 | 베타 출시 | POS 연동, 단골 DB, 수동 알림 발송 |
| 4~6개월 | 유료 전환 | AI 추천 메시지, ROI 대시보드, 가격 정책 적용 |
| 7~12개월 | 다채널 확장 | LMS·이메일, 매장 그룹 분석, B2B 영업 기능 |
| 13~18개월 | POS 연동 확장 | 주요 정육 POS사·카드사 API 통합, 데이터 라이선스 시범 |

### 4.4 시장 트렌드 (Why Now)

세 흐름이 동시에 변곡점을 만들고 있습니다.

1. **AI 에이전트 기술 성숙** — 머신러닝 이탈/수요 예측 + LLM 개인화 텍스트가 *실용 수준* 도달. POS 로컬 데이터 활용 적기.
2. **정육 소비 회복** — 1인당 연 정육 소비 +15% (5년) 성장. 신규 매장 대비 *기존 매장 단골 ROI* 상승.
3. **정부 디지털 전환 정책** — 소상공인 바우처 사업이 *AI SaaS 매칭 채널*로 직접 작동.

→ *AI 기술 성숙 · 정육 시장 회복 · 정부 보조*가 *처음으로* 동시에 갖춰진 시점.

## 5. 비즈니스 모델 (Business Model)

### 5.1 수익 모델

**월 정액 SaaS + 문자 건당 과금**

| 구분 | 금액 | 설명 |
|------|------|------|
| Basic 구독 | 월 **33,000원** | AI 단골관리 전 기능 |
| 문자 발송 | 건당 **33원** | 매입가 대비 마진 포함 |

**예상 ARPU (매장 월)**: 약 **8~12만원** *(가설)*
*(구독 33,000원 + 문자 평균 1,500~2,500건 × 33원)*

**가격 산정 근거**: 베타 사장님 가격 인터뷰 기반. *알바생 시급 1~2시간 분량* 으로 정육점 사장님 부담 수준 검증.

**기대 효과 (제품 가치 가설 — 실증 데이터 없음)**
- 매장 매출 평균 **+15%** *(목표치, 베타에서 측정 예정)*
- 마케팅비 **-50% 이상** *(목표치, 기존 문자 마케팅 대행 대비)*

### 5.2 단위 경제학 (Unit Economics) *(가설 — 베타 누적 후 갱신)*

| 지표 | 목표 | 업계 우수 기준 |
|------|------|---------------|
| **CAC** | 5~9만원 | — |
| **LTV** | 약 200만원 *(가설)* | — |
| **LTV / CAC** | 약 25배 *(가설)* | 3배 이상 |
| **월 이탈율** | 3% *(가설)* | SMB SaaS 평균 5~7% |
| **Gross Margin** | 75~80% *(가설)* | SaaS 전형 |
| **Payback Period** | 1개월 미만 *(가설)* | <12개월 |

> ⚠️ Unit Economics 가설치는 베타 30매장 누적 후 *보수적 재산정* 예정.

### 5.3 성장 전략 (GTM)

**마케팅·판로 전략 (채널 믹스)**

| 채널 | 비중 | 설명 |
|------|------|------|
| 직판 (웹·전화·방문) | 30% | 자체 영업 채널 |
| 파트너 유통사 (㈜더담우) | 20% | 연 매출 1,000억 정육 유통사 영업망 |
| POS사 협업 (매출 쉐어) | 20% | 정육 POS 1~2사 협업 |
| 조합·협회 제휴 | 10% | 정육협동조합·한우자조금 |
| 정부 바우처 | 20% | 소상공인 디지털 전환 바우처 |

**Phase별 GTM**
- **Phase 1 (26~27)**: 파일럿 1매장 → 더담우 5매장 → 35매장 베타
- **Phase 2 (28)**: 정식 출시, 누적 366매장. 직판 + 더담우 영업 본격화
- **Phase 3 (29~30)**: 정육 시장 주도 — 3,000매장. POS사·조합·바우처 채널 가속
- **Phase 4 (31~)**: 마트·반찬가게 등 2개 이상 인접 산업 확장

## 6. 경쟁 분석 (Competition)

### 6.1 경쟁 환경

이 시장의 진짜 경쟁자는 *다른 정육 CRM이 아닌*, 사장님이 *지금 쓰고 있는 종이 장부·머릿속 기억·카톡 채널*입니다 — *No Action* 이 가장 강한 경쟁.

### 6.4 "왜 대기업이 못 하는가" (Q&A 대비)

- **단가 매력 부족** — 동네 매장 ARPU 18만원/월은 카카오·네이버·POS 대기업의 *영업 인건비 ROI 불성립*. 동네 매장 *직접 영업*은 그들의 효율 비즈니스 모델과 맞지 않음.
- **카테고리 깊이 부족** — 부분육 단가·신선도·정육 단골 패턴은 *정육 특화 학습 데이터* 없이 못 만듦. *우리는 이 카테고리에 *전부 베팅*, 그들은 *전 카테고리 평균* 추구*.
- **사장님의 *대기업 *불신***— 동네 사장님은 *카카오·네이버에 데이터 *주는 것에 *민감*. *작은 회사가 *동맹*처럼 들어가는 것*이 동네 정육점 침투에 유리.
