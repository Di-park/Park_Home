## 1. Executive Summary

### 1.1 핵심 요약

**㈜위브원의 또와는 *고객관리·마케팅·재고 관리·발주까지 스스로 하는*, *정육점 사장님의 첫 AI 직원*입니다.** 사장님이 *눈앞의 손님에게만 집중*하는 동안, 또와가 *동시에* 단골·재고·이탈을 챙기는 — *Zero-Task AI 에이전트*. 토스플레이스·캐시노트가 자영업 *수평* 카테고리(결제·장부·일반 CRM)를 점유하는 동안, 우리는 *정육 수직 카테고리*(부분육·계절·명절·가구단위)를 *Zero-Task UX*로 끝까지 파는 회사입니다.

국내 정육점 약 **57,000개소 (시장 약 2,200억원)**, 정육점 매출의 **70% 이상이 단골 기반 반복 구매** *(파일럿 매장 거래 데이터 기반)* 이지만, 사장님은 *고객관리를 기억에 의존*해 단골 이탈을 인지하지 못한 채 매출을 잃고 있습니다. 더 근본적으로는 *아침부터 저녁까지 장사 준비·손질·응대·마감* 까지 다 해야 하는 사장님에겐 *체계적으로 고객을 관리할 시간·비용적 여유* 자체가 없습니다.

또와는 (1) *POS 거래만 들어오면* 단골 명단·구매 이력이 자동 누적, (2) *이번 주 챙겨야 할 단골*을 AI가 골라 푸시, (3) *정육점 말투의 개인화 메시지*를 자동 생성해 알림톡 발송, (4) *재고 분석 → 자동 마케팅·발주 제안*, (5) *이탈 예측 → 자동 대응* — 사장님 시간 *주 5초 (리포트 확인)* 로 *기존엔 불가능했던 매장 운영 OS*를 가능하게 합니다.

**제품 가치 가설**: 매장 매출 **+15%** / 마케팅·재고 비용 **-50%**. *현 시점 실증 데이터 없음 — Pre-Seed 1차 6개월 마일스톤이 이 측정 자체*입니다.

**Why Now**: 도메인 특화 AI 에이전트 시대 — 법률(Harvey)·의료(Hippocratic AI)·영업(11x)이 *수직 도메인* 자동화를 선점한 동안, *동네 자영업 도메인*은 아직 **0개사**. 또와가 정육에서 시작.

**진행 상태**: 정육점 **1개소 파일럿 도입** — 단골 자동 분류 / 메시지 생성 / 문자 발송 *워크플로 가동 중* (누적 거래 약 5만 건 / 단골 약 2,100명). *도입 전/후 매출 효과는 측정 시작 전*. 협력사 **㈜더담우** (연 매출 1,000억 정육 유통사) — *5개 점포 영업망 협력 합의*, **도입은 Pre-Seed 후 6개월 내 순차 시작 예정**. 18개월 후 **공헌이익 양수 + 유료 매장 100~150** *(가설)* 도달 → Series A 도전 목표.

이를 위해 **Pre-Seed 라운드 5억원** *(희석)* + 정부 R&D 7억 *(비희석)* 조달을 제안합니다.

## 2. 문제 정의 (Problem)

### 2.1 해결하려는 문제

동네 정육점 사장님은 *단골을 잃는 줄도 모른 채* 잃고 있습니다. 이는 *세 가지 구조적 부재* 때문입니다.

**① 단골 정보가 *사장님 머릿속*에만 있다**
파일럿 매장 한 곳만 봐도 *5회 이상 방문 단골이 약 2,100명*. 사장님이 이름·구매 패턴을 인지하는 비율은 극소수. 정육점 매출의 **70% 이상이 단골 기반**인데도 *단골 자체가 데이터로 존재하지 않음*. 종이 장부·카톡 채널·POS 단편 데이터에 *분산*되어 *통합 조회 불가*.

**② 단골이 떠나기 전 *어떠한 신호도 알 수 없다***
방문 주기가 늘어나도, 객단가가 떨어져도 사장님은 모른다. *다른 가게로 옮긴 후*에야 알아챈다. 매장 자체에 *이탈 감지·예측·대응 메커니즘*이 0.

**③ *단골을 관리할 수 있는 여유가 없다***
아침부터 저녁까지 *장사 준비 · 손질 · 응대 · 마감* 까지 다 해야 하는 사장님에겐 *체계적으로 고객을 관리할 시간적·비용적 여유*가 부족. 의지·도구의 문제가 아니라 *물리적 시간*의 문제 — 그래서 *사장님 손이 0인* 자동화가 유일한 해.

### 2.2 기존 해결 방식의 한계

| 기존 방식 | 한계 |
|-----------|------|
| 종이 장부 | 검색·통계 불가, 분실·소실 위험 |
| 카톡 채널 | 알림 발송은 되지만 *고객·구매 데이터 분리*, 사장님이 매번 작성·발송 |
| 종합 POS의 단골 모듈 | 단말 교체 비용 300~500만원, 정육 특화 부재 |
| 본사 가맹형 (백화점·축산기업) | 동네 자영업 정육점이 가맹 진입 불가 |
| 사장님 머릿속 기억 | 30명 수준 — *진짜 시장(2,100명+)*의 *1~2%* |

→ *진입 비용 낮음 + 정육 특화 + 사장님 손 = 0* 의 *교집합*이 *시장에 없음*. 이 공백이 또와의 자리입니다.

## 3. 솔루션 (Solution)

### 3.1 제품/서비스 개요

**또와는 정육점 사장님의 *행동 횟수 = 0* 을 목표하는 *Zero-Task AI 에이전트*입니다.** 사장님이 *눈앞의 손님에게만* 집중하는 동안, 또와가 *동시에* 단골·재고·이탈을 챙깁니다 — *알아서 다 해주는 보이지 않는 막내 직원*.

### 3.2 Zero-Task 작동 방식 (사장님 행동 = 주 5초)

1. **앱 다운로드 + POS 연동 (5분, 1회성)** — 매장 카운터에서 설치·연결, *발송 정책 사전 설정* (안전 가드레일)
2. **단골 명단 자동 누적** — POS 거래가 들어올 때마다 고객·구매 부분육·금액이 자동 분류 *(사장님 행동 0)*
3. **AI가 이번 주 챙길 단골 자동 선정** — 사장님은 보지도 않음 *(사장님 행동 0)*
4. **정육점 말투 개인화 메시지 자동 작성·발송** — *사장님 검토 단계 없음* *(사장님 행동 0)*
5. **재고 분석 → 자동 마케팅** — 과재고 부위 자동 프로모션 *(사장님 행동 0)*
6. **이탈 예측 → 자동 대응** — 이탈 임박 단골에게 자동 쿠폰·메시지 *(사장님 행동 0)*
7. **재방문·매출 자동 추적 → 주간 리포트 1장** — 사장님은 *주 5초* 만 확인 *(사장님 행동 = 주 5초)*

→ **사장님 행동 부담 = 1주에 5초**. 토스플레이스·캐시노트 등 *수평 도구의 *사장님 매번 작업 필요* 모델*과 정반대.

### 3.3 핵심 기능 — 3축

**축 1. 매장 데이터 기반 단골 관리** (Wedge — 첫 진입 가치)
- POS 거래 → 단골 자동 분류 (5회+ 방문 = 단골 등급)
- AI 자동 선정 → 정육점 말투 개인화 메시지 → 한 번 탭 발송
- 이탈 예측 → 임박군에 자동 쿠폰
- 재방문 추적·주간 리포트 자동 생성

**축 2. 재고량 분석 CRM 활동**
- 과재고 부위 자동 마케팅 (예: 목살 재고 多 → 단골 중 목살 선호자 자동 푸시)
- 신선도 기반 추천 (오늘 들어온 부위 → 단골 알림)
- 마케팅 ROI 자동 측정

**축 3. 판매량 예측 기반 발주 제안·자동화**
- 단골 패턴 + 명절·계절 변수 → 발주량 자동 산정
- 도매상 연동 시 *자동 발주 송신* (Future)
- 재고 회전율·마진 분석 리포트

### 3.4 기술 스택 개요

- **모바일**: React Native (iOS·Android 단일 코드베이스)
- **추천 엔진**: 단골 행동 시계열 분석 + LLM 메시지 생성
- **알림 발송 인프라**: 카카오 알림톡 · LMS · 이메일 다채널
- **백엔드**: Python/FastAPI + PostgreSQL + Redis
- **장기**: POS·카드사 API 연동, 도매상 API 연동, 데이터 라이선스 사업화

### 3.5 제품 로드맵

| 시기 | 마일스톤 | 주요 기능 |
|------|---------|----------|
| 0~6개월 | 베타 N=30 | POS 연동, 단골 DB, 자동 메시지 발송, 효과 측정 인프라 |
| 6~12개월 | 유료 전환 (PMF) | AI 추천 메시지, ROI 대시보드, 가격 정책 적용, 재고 분석 v1 |
| 12~18개월 | 공헌이익 양수 | LMS·이메일, 매장 그룹 분석, B2B 영업 기능, 발주 제안 |
| 18~ | Series A 진입 | POS·카드사·도매 API 통합, 데이터 라이선스, 유통 중개 |

## 6. 경쟁 분석 (Competition)

### 6.1 경쟁 환경 — 수평 점유 SaaS의 *빈자리*

자영업 SaaS 시장은 *수평 카테고리*(전 업종 공통 결제·장부·일반 CRM)와 *수직 카테고리*(특정 업종 깊이)로 갈라집니다. **수평은 이미 토스플레이스·캐시노트가 점유 중**입니다. *정육 특화* 와 *Zero-Task UX* 두 축의 교집합 — 즉 *수직 × Zero-Task* 사분면은 *비어 있습니다*.

```
   Zero-Task (사장님 손 = 0)
                  ↑
                  │                                ★ 또와
                  │                                  (정육 100% × Zero-Task)
                  │
                  │  토스플레이스 CRM ●
                  │  캐시노트 CRM ●
                  │                              ● 정육점 SYSTEM 대리점
                  │
   High-Task ──────────────────────────────→
        수평 (전 자영업)         수직 (정육 특화)
```

### 6.2 경쟁 카테고리 매핑

| 플레이어 | 산업 내 포지션 | 정육 특화 | 자동화 |
|---------|---------------|---------|------|
| **또와 (㈜위브원)** | 시작 단계 | ✓ | ✓ |
| 토스플레이스 CRM | 자영업 전반 — *고객관리* 우위 | ✗ | △ |
| 캐시노트 CRM | 자영업 전반 — *매출관리* 우위 | ✗ | ✗ |
| 정육점 SYSTEM 대리점 | *정육 내 점유율* 우위 | △ | ✗ |

> *같은 정육 매장에서 또와 + 토스플레이스/캐시노트/정육점 SYSTEM 대리점 공존 가능. 결제·장부·POS는 그들이, 단골·재고·발주 자동화는 또와가.*

### 6.3 Market Insight — *큰 경쟁자도 못 뚫은 시장*

**큰 경쟁자도 못 뚫은 정육점 시장. — *이 시장이 비어있는 이유 = 우리의 해자*.**

**① 사실 — 토스플레이스·캐시노트도 정육점은 못 뚫었다**
- 자영업 전반엔 빠르게 침투했지만, *정육점 사장님은 안 씀*
- 베타 매장 사장님 *전원이 "바꿔본 적 없다"* *(현장 인터뷰)*

**② 이유 — "잘 되면 안 바꾼다"**
- 정육점 사장님의 *보수적 충성도*. 한 번 안착하면 *몇 년 그대로*
- 진입 장벽이 높음 = 들어간 회사에겐 *시간을 벌어주는 해자*

**③ 그래서 — 가치 제안이 달라야 한다**

| | 전략 | 대표 카피 |
|---|------|------|
| **경쟁사 접근** | POS·매출관리 등 *모든 오프라인 매장*에서 쓸 수 있는 *다양·유용한 기능* 중심 | *"만 원 써서 새로 2만 원 버세요"* — 매출 증가 톤 |
| **또와 접근** | *정육 도메인*의 비효율 업무를 *삭제*, *산업 특화 편리함*을 무기로 시장 침투 | *"만 원 쓰던 거, 오천 원만 써도 2만 원 그대로"* — 비용 절감 톤 |

> **정육 도메인 완전 특화 모델로 이 견고한 시장을 *뚫어*냅니다.**

### 6.4 경쟁 우위 / 해자

| 차별점 | 종류 | 시간 효과 |
|--------|------|----------|
| 정육 도메인 학습 데이터 (부분육·계절·명절·가구단위) | 데이터 해자 | 누적될수록 *격차 확대* |
| Zero-Task UX 신뢰 자산 (발송 정책·안전 가드레일·예외 케이스) | 운영 해자 | 데이터 + 운영 시간이 둘 다 모이는 회사만 가능 |
| 사장님 *직접 가입* (POS 교체 불필요) | 구조 차별 | 수평 SaaS의 단가 ROI 불성립 |
| 동네 클러스터 침투 + 사장님 추천 네트워크 | 네트워크 효과 | 일정 침투 후 *후발 영업 비용 폭증* |
| POS·카드사·도매 데이터 라이선스 협상력 | 후방 통합 | 매장 수가 곧 협상력 |

### 6.5 "왜 토스플레이스·캐시노트가 못 하는가" (Q&A 대비)

- **수평 비즈니스 모델 구조** — 그들의 ROI는 *전 자영업 공통* 기능에서 나옴. 정육 *5개 도메인 축* 학습 데이터를 *그들의 인력·예산 우선순위*에 넣는 일은 없음.
- **Zero-Task UX 책임 한계** — 수평 SaaS는 *사장님에게 최종 발송 버튼*을 맡기는 구조에서 못 벗어남. *업종별 안전 가드레일* 누적이 *전 업종 동시*로는 불가능.
- **보수적 정육 사장님이 안 듣는 카피** — 수평사의 *매출 증가* 톤은 *"잘 되면 안 바꾼다"* 사장님 귀에 닿지 않음. 우리는 *비용 절감* 톤으로 처음 귀를 엶.

### 6.6 "왜 대기업(카카오·네이버)이 못 하는가"

- **단가 매력 부족** — 동네 매장 ARPU 약 10만원/월은 카카오·네이버 대기업의 *영업 인건비 ROI 불성립*.
- **카테고리 깊이 부족** — 부분육 단가·신선도·정육 단골 패턴은 *정육 특화 학습 데이터* 없이 못 만듦.
- **사장님의 대기업 데이터 불신** — 동네 사장님은 *카카오·네이버에 데이터 *주는 것에 민감*. 작은 회사가 *수직 카테고리 동맹*으로 들어가는 것이 침투에 유리.

## 11. 비전 (Vision)

> **기술 발전의 혜택에서 소외된**
> **소상공인의 도메인에 깊숙이 파고들어**
> **기술과의 거리감을 줄이는 비즈니스를**
> **하겠습니다.**

— *정육점은 그 시작입니다.*

### 11.1 미션

대기업·전문직·테크 도메인은 AI 시대의 *직접 수혜자*가 되었지만, *동네 자영업 사장님*은 아직 *기술과의 거리감* 속에 있습니다. 또와는 이 거리감을 *도메인 깊숙이* 들어가 *AI 직원* 형태로 좁히는 회사입니다.

### 11.2 단계별 확장 비전

- **Stage 1 (2026~2028)**: 정육 수직 카테고리 *Zero-Task 운영 OS*로 안착
- **Stage 2 (2028~2030)**: 정육 시장 리더 (Shopify·Toast 수준)
- **Stage 3 (2030~)**: *인접 수직 카테고리* (반찬가게·마트·미용·서비스 등) 로 *AI 직원 모델* 확장
- **Stage 4 (장기)**: 소상공인 전반의 *기술 격차 해소 플랫폼* — Mission-driven 회사로 정착
