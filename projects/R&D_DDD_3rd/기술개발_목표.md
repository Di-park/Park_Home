# 기술개발 목표

## 1. 개발 배경 및 필요성

### ① AI 시대, 소상공인의 구조적 소외
- 생성형 AI 도구의 대중화로 지식근로자의 업무 자동화 가속, 영업·마케팅·고객관리까지 AI 에이전트 위임 단계 진입
- 반면 오프라인 소상공인은 시간·비용·기술 접근성의 삼중 장벽으로 AI 활용 사각지대에 위치
- 골목상권 사업자는 재료 손질, 대면 판매, 고객 응대, 판촉, 단골 정보 암기 등 모든 운영 업무를 1인 또는 소수 인력으로 감당 → "누구나 AI로 업무를 자동화할 수 있다"는 명제 비적용

### ② 고객관리 영역의 디지털 격차 심화
- 대기업·프랜차이즈·이커머스: 풍부한 데이터 기반 고도화된 CRM과 개인화 마케팅 체계 보유
- 동네 가게: 고객 정보가 사장님 개인 기억에 전적 의존, 체계적 고객관리 불가
- 시중 범용 CRM 솔루션: 사무직 세일즈 환경 전제 설계 → 정육점·반찬가게·카페 등 소상공인 업종별 특수 맥락 반영 불가

### ③ 소상공인 현장 특화 AI 에이전트의 필요성
- 오프라인 매장은 방문주기·객단가 감소가 매출에 즉각 직결되는 구조
- 매장별·고객별 특성을 반영한 이탈 징후 자동 감지 및 마케팅 자동화 수단 부재
- 머신러닝 기반 예측 모형 및 LLM 개인화 텍스트 생성 기술의 실용 수준 도달 → 소상공인 POS 로컬 데이터를 활용한 현장 특화 AI 에이전트 개발·실증의 적기 도래

## 2. 개발 현황 및 목표

### 2.1 최종 개발 목표: 소상공인 현장 특화 AI 에이전트

> **"사장님이 아무것도 하지 않아도 AI가 고객을 분석하고 마케팅을 자동 집행"**하는 Zero-Task 구조의 현장 특화 AI 에이전트

| 구분 | 내용 |
|------|------|
| **제품명** | 소상공인 현장 특화 AI 고객관리 에이전트 |
| **핵심 가치** | POS 로컬 데이터 기반 고객 분석 → 타겟 추출 → 개인화 문구 생성 → 최적 시점 자동 발송 |
| **첫 적용 도메인** | 정육점 (단골 의존도 70% 이상, 개인화 변수 다층성 최적) |

---

### 2.2 현재 개발 현황 (Pre-R&D 단계)

| 항목 | 현황 |
|------|------|
| **파일럿 매장** | 1개 매장 POS 데이터 연동 완료 |
| **고객 분석** | POS 데이터 기반 고객별 방문 변화율 산출 체계 구축 |
| **문구 생성** | 품목 기반 LMS 마케팅 문구 제작 기능 구현 |
| **발송 시스템** | 제작된 문구 즉시 발송 가능한 시스템 구축 |

**현 시스템의 한계:**
- 타겟 고객 추출: 수동 분석 의존, 자동화된 이탈 예측 모형 부재
- 문구 개인화: 품목 단위 일괄 문구, 고객별 맞춤 개인화 미적용
- 발송 시점: 일괄 발송, 고객별 최적 시점 판단 불가
- 자동화 수준: 사장님 개입 필수, Zero-Task 구조 미달성

---

### 2.3 본 과제 개발 목표: AI 에이전트 핵심 의사결정 엔진

> AI 에이전트가 **'누구에게(타겟)'**, **'무엇을(개인화 문구)'**, **'언제(최적 시점)'** 마케팅할지 스스로 판단하고 실행하는 **지능형 핵심 모듈** 개발

현재 구축된 시스템(POS 연동, 문구 발송)은 AI 에이전트의 **손과 발** 역할을 수행함. 그러나 진정한 AI 에이전트로 기능하기 위해서는 데이터를 분석하고, 타겟을 선별하며, 개인화된 메시지를 생성하는 **의사결정 체계**가 필수적임. 본 과제는 이 의사결정 체계를 구성하는 핵심 엔진을 개발하여, 기 구축 시스템과 결합함으로써 완전한 AI 에이전트 구현을 목표로 함.

#### 본 과제 핵심 개발 영역

| 영역 | 현황 → 목표 | 핵심 기술 |
|------|------------|----------|
| **① 타겟 추출** | 수동 분석 → AI 자동 추출 | RF 이중모형 기반 이탈 예측, 고객별 이탈 기준 자동 도출 |
| **② 개인화 문구** | 품목 단위 일괄 → 고객별 맞춤 | LLM 기반 개인화 텍스트 생성, 매장 내 파편 데이터 통합 |
| **③ 발송 최적화** | 일괄 발송 → 최적 시점 자동 판단 | 고객별 반응률 기반 발송 시점 최적화 |
| **④ 완전 자동화** | 사장님 개입 필수 → Zero-Task | 전 과정 자동화 파이프라인, 월 1회 자동 재학습 |

#### 본 과제의 핵심 개발 범위

```
┌─────────────────────────────────────────────────────────────┐
│          AI 에이전트 핵심 의사결정 엔진 (본 과제)              │
│          "누구에게 · 무엇을 · 언제" 자동 판단 체계            │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────────┐    ┌─────────────────────┐        │
│  │  ① 타겟 추출 엔진   │    │  ② 개인화 생성 엔진  │        │
│  │    (누구에게)       │    │    (무엇을)         │        │
│  │                     │    │                     │        │
│  │  • 이탈 위험 고객    │    │  • 파편 데이터 통합  │        │
│  │    자동 식별        │    │    (구매이력+방문   │        │
│  │  • 고객별 맞춤      │    │    주기+선호부위)   │        │
│  │    이탈 기준 도출   │    │  • LLM 기반 1:1    │        │
│  │  • 재구매 확률      │    │    맞춤 메시지     │        │
│  │    예측             │    │                     │        │
│  └─────────────────────┘    └─────────────────────┘        │
│                    ┌─────────────────────┐                 │
│                    │  ③ 발송 최적화 엔진  │                 │
│                    │    (언제)           │                 │
│                    └─────────────────────┘                 │
└─────────────────────────────────────────────────────────────┘
                              ↓ 연동
┌─────────────────────────────────────────────────────────────┐
│                   기 구축 시스템 (Pre-R&D)                   │
│                   데이터 수집 및 실행 인프라                  │
├─────────────────────────────────────────────────────────────┤
│     POS 연동  →  방문 변화율 산출  →  문구 발송 시스템       │
└─────────────────────────────────────────────────────────────┘
```

**① 적합한 타겟 추출 (이탈 예측 엔진)**
- 5개 매장 개인별 이탈 기준 자동 도출이 가능한 RF 이중모형 개발
- 매장별 이탈 모형 운영 자동화 구조 및 월 1회 자동 재학습 파이프라인
- 이탈 위험 고객 리스트 자동 생성 및 AI 어시스턴트 탑재

**② 개인화 문구 생성 (LLM 개인화 엔진)**
- 매장 내 파편화된 데이터(구매이력, 방문주기, 선호부위, 가구단위, 계절, 명절) 통합 활용
- 화이트리스트 기반 LLM 프롬프트 엔진으로 오류 최소화
- 개인화 Depth 변화 시에도 품질 유지되는 문구 자동 생성

### 2.4 단계별 개발 목표

| 단계 | 구분 | 목표 |
|------|------|------|
| **1단계** | 연구 | 5개 매장 개인별 이탈 기준 자동 도출이 가능한가? (RF 이중모형 개선) |
| 고객 이탈 예측 | 기술 | 매장별 이탈 모형 운영 자동화 구조 / 월 1회 자동 재학습 파이프라인 |
| | 제품 | 이탈 위험 고객 리스트 AI 어시스턴트 탑재 |
| **2단계** | 연구 | 품목별 판매 추세 자동 분류가 가능한가? (XGBoost 기반 수요예측 모형) |
| 품목별 수요 예측 | 기술 | 수요예측 모형 자동 재학습 / 고객-품목 선호 자동 매핑 구조 |
| | 제품 | 품목별 판매 추세에 따른 타겟 고객 자동 추출 탑재 |
| **3단계** | 연구 | 오류 최소화 최적 프롬프트 구조는? / 개인화 Depth 변화 시 품질 유지되는가? |
| LLM 개인화 문자 | 기술 | 화이트리스트 기반 LLM 프롬프트 엔진 / 실사용 오류 자동 모니터링 |
| | 제품 | 개인화 문자 자동 생성·발송 AI 어시스턴트 탑재 |
| **4단계** | 연구 | 개인화 수준별 마케팅 효과 차이 유의미한가? |
| 효과 검증 | 기술 | A/B 테스트 자동화 구조 / 효과 측정 대시보드 |
| | 제품 | 효과 분석 리포트 자동 생성 기능 탑재 |
| **5단계** | 연구 | 전체 파이프라인 통합 시 현장 적용 가능한가? |
| 현장 실증 | 기술 | Zero-Task 완전 자동화 파이프라인 |
| | 제품 | 소상공인 현장 특화 AI 에이전트 v1.0 출시 |

## 3. 정육점 선정 사유

| 특성 | 설명 |
|------|------|
| **단골 의존도** | 매출의 70% 이상이 단골 고객 반복 구매에서 발생 → 이탈 방지 효용 극대화 |
| **개인화 변수 다층성** | 부위·용도·가구단위·계절·명절 등 5개 이상 도메인 축 동시 활용 가능 |
| **데이터 검증 용이** | 재방문 주기·객단가 변동 명확 → AI 효용 실증 최적 도메인 |
| **확장 가능성** | 정육점 → 반찬가게·떡집·수산물·꽃집 등 주기 방문형 소매업 수평 확장 |
