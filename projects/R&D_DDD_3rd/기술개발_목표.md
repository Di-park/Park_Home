# 기술개발 목표

## 과제명
**소상공인 오프라인 리테일 마케팅 의사결정 자동화를 위한 자가학습형 AI 운영체제 개발**

---

## 1. 개발 현황: 규칙 기반 마케팅 자동화 도구

> **규칙 기반 고객 분류 → 메시지 생성 → 수동 발송**

현재 1개 파일럿 매장에서 운영 중인 규칙 기반 마케팅 자동화 도구의 기능 구성:

### 기능 1: 규칙 기반 고객 분류
- 월 1회 고객 구매 데이터 수집
- 고객 방문 변화율을 일반통계 규칙으로 계산
- **분류 기준**:
  - 변화율 낮음 → 정기 방문 고객 (안정 고객)
  - 변화율 증가 → 이탈 위험 고객

### 기능 2: 문구 자동 생성 (LLM)
- 사장님이 홍보 품목 및 할인 여부 선택
- LLM 호출하여 약 400자 마케팅 문구 생성

### 기능 3: 고객별 문자 발송
- 사장님이 생성 문구를 검토·수정
- 두 분류 중 타겟 고객군 선택 후 수동 발송

---

## 2. 개발 목표: 자가학습 마케팅 루프 기반 AI 마케팅 운영체제

> **데이터 수집 → 고객/상품 분석 → 마케팅 액션 큐레이션 → 성과 학습 → 재추천**

### 핵심 개념

**본 시스템의 핵심은 AI 마케팅 어시스턴트를 통해 분석·판단·실행을 통합하고, 사장님의 복잡한 마케팅 의사결정을 즉시 실행 가능한 1~2개의 액션으로 단순화하는 데 있음.**

- 고객 데이터(CRM)와 상품 데이터(POS)를 통합
- **'무엇을 · 누구에게 · 언제 판매할 것인지'** 자동 결정 구조

---

### 기능 1: 자동 데이터 업데이트 + ML 기반 고객 분류

| 현황 | 목표 |
|------|------|
| 월 1회 수동 데이터 수집 | **주 3회 자동 수집·정제** |
| 일반통계 규칙 기반 분류 | **ML 기반 복합 이탈 점수 모형** |
| 단순 2분류 | **고객 행동 기반 다차원 분류** |

**세부 기능:**
- POS 시스템 연동을 통한 고객 구매 데이터 자동 수집·정제 (주 3회)
- 복합 이탈 점수 모형 기반 고객 분류
- 부위별 수요 변동 분석 및 고객별 선호 부위 패턴 파악

---

### 기능 2: 정육점 특화 개인화 문구 생성 (LLM)

| 현황 | 목표 |
|------|------|
| 사장님이 품목 선택 | **AI가 홍보 필요 품목 추천** |
| 일반 마케팅 문구 | **정육점 특화 + 개인화 문구** |
| 단일 문구 생성 | **개인화 깊이(Depth) 조절 가능** |

**세부 기능:**
- AI 어시스턴트가 분석 결과를 사장님께 설명
  - *"이탈 확률 30% 이상인 고객 15명에게 맞춤 문자를 보내세요"*
  - *"항정살 판매가 10% 감소했습니다. 항정살 선호 고객에게 메시지를 보내세요"*
- 사장님이 품목 디테일(가격, 원산지, 특징 등) 입력
- LLM이 사실 오류 최소화, 적절한 추론, 정육점 특화 문구 생성
- 개인화 깊이(Depth) 변화 옵션 제공 (일반 → 고객명 포함 → 선호부위 반영 등)

---

### 기능 3: 고객 맞춤 문자 발송

| 현황 | 목표 |
|------|------|
| 사장님이 타겟 선택 | **AI가 맞춤 발송 리스트 추천** |
| 수동 발송 | **추천 → 승인 구조** |

**세부 기능:**
- AI 어시스턴트가 홍보 품목 × 고객 패턴 × 효율적 개인화 깊이를 연계 판단
- 생성된 문자와 맞춤 발송 리스트 제시
- 사장님은 필요시 메시지 수정 후 승인
- 승인 즉시 문자 자동 발송

---

### 기능 4: 자가학습 기반 마케팅 의사결정 최적화 엔진

> 본 기능은 4~5단계에서 고도화 예정

**세부 기능:**
- **반응 추적**: 문자 발송 후 고객 반응(재방문, 구매) 추적
- **효과 분석**: 고객별 효과적인 문구 패턴 및 발송 타이밍 기록
- **비효과 분석**: 반응 없는 고객 대상 문자 빈도 조정, 이탈 가능성 재판단
- **AI 큐레이션 인터페이스 고도화**:
  - 고객군 × 품목 × 타이밍 결합 마케팅 액션 추천
  - 각 큐레이션 시 추천 이유 및 예상 효과 제시
  - 예상 매출 효과 또는 반응률 수치 제시

---

## 3. 기대 효과

### 3.1 핵심 지표 개선

| 기능 | 기대 효과 |
|------|----------|
| **이탈 예측** | 재방문율 **+15%** 향상 |
| **품목 수요 분석** | 특정 부위 매출 **+10%** 증대 |
| **개인화 메시지** | 메시지 반응률 **+20%** 개선 |

### 3.2 사장님 경험 변화

| 구분 | 기존 | 도입 후 |
|------|------|--------|
| **Step 1** | 뭐 팔지 고민 | 대시보드 접속 |
| **Step 2** | 고객 고르기 | 오늘 할 마케팅 2개 확인 |
| **Step 3** | 문자 쓰기 | 승인 |
| **Step 4** | 발송 | 끝 |

**핵심 변화:**
> 기존의 **'분석 → 판단 → 실행'** 복잡한 과정을  
> **'추천 → 승인'** 구조로 전환

---

## 4. 확장 전략

본 시스템 완료 시 **고객 × 상품 × 타이밍** 기반 의사결정 구조를 갖추어, 채널·데이터·업종 확장이 자연스럽게 이루어지는 구조임. 마케팅 의사결정이 특정 채널이나 업종이 아닌 **데이터 구조에 의해 정의**되기 때문에 가능한 확장임.

### 1단계: 예측 기반 마케팅 실행 고도화

| 영역 | 확장 내용 |
|------|----------|
| **예측 확장** | 날씨·요일·이벤트 데이터 결합 사전 마케팅 |
| | *"비 오는 날 삼겹살 수요 예상 → 사전 할인 이벤트 메시지 발송"* |
| **채널 확장** | 앱푸시, 쿠폰 발행, 오프라인 이벤트 연동 |

### 2단계: 산업 확장 및 플랫폼화

| 영역 | 확장 내용 |
|------|----------|
| **업종 확장** | 정육점 → 식자재 유통 → 로컬 리테일 |
| **플랫폼화** | 리테일 AI 마케팅 인프라로 확장 |
| | AI 큐레이션 엔진 API 형태 제공 |
| | 다양한 리테일 사업자 연결 구조 |

## 5. 단계별 개발 목표 (요약)

| 단계 | 핵심 목표 | 산출물 |
|------|----------|--------|
| **1단계** | ML 기반 이탈 예측 모형 개발 | 5개 매장 검증, 이탈 예측 엔진 |
| **2단계** | 품목별 수요 예측 모형 개발 | 부위별 수요 분석, 고객-품목 매핑 |
| **3단계** | LLM 개인화 문구 생성 고도화 | 정육점 특화 프롬프트 엔진, 개인화 Depth 옵션 |
| **4단계** | 자가학습 기반 효과 검증 | A/B 테스트, 반응 추적, 최적화 엔진 |
| **5단계** | AI 마케팅 운영체제 통합 | Zero-Task 대시보드, 추천→승인 UX |
