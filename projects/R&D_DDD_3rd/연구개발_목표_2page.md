# 연구개발 목표

## 과제명
**소상공인 오프라인 리테일 마케팅 의사결정 자동화를 위한 자가학습형 AI 운영체제 개발**

---

## 1. 개발 배경 및 필요성

### ① AI 시대, 소상공인의 구조적 소외
- 생성형 AI의 대중화로 지식근로자의 업무 자동화 가속, 영업·마케팅·고객관리 영역까지 AI 에이전트 위임 단계 진입
- 반면 오프라인 소상공인은 시간·비용·기술 접근성의 삼중 장벽으로 AI 활용 사각지대에 위치
- 골목상권 사업자는 재료 손질, 대면 판매, 고객 응대, 판촉, 단골 정보 암기 등 모든 운영 업무를 1인 또는 소수 인력으로 감당 → "누구나 AI로 업무를 자동화할 수 있다"는 명제 비적용

### ② 고객관리 영역의 디지털 격차 심화
- 대기업·프랜차이즈·이커머스: 풍부한 데이터 기반 고도화된 CRM과 개인화 마케팅 체계 보유
- 동네 가게: 고객 정보가 사장님 개인 기억에 전적 의존, 체계적 고객관리 불가
- 시중 범용 CRM 솔루션: 사무직 세일즈 환경 전제 설계 → 정육점·반찬가게·카페 등 소상공인 업종별 특수 맥락 반영 불가

### ③ 소상공인 현장 특화 AI 마케팅 운영체제의 필요성
- 오프라인 매장은 방문주기·객단가 감소가 매출에 즉각 직결되는 구조
- 매장별·고객별 특성을 반영한 이탈 징후 자동 감지 및 마케팅 자동화 수단 부재
- 머신러닝 기반 예측 모형 및 LLM 개인화 텍스트 생성 기술의 실용 수준 도달 → 소상공인 POS 로컬 데이터를 활용한 자가학습형 AI 마케팅 운영체제 개발·실증의 적기 도래

## 2. 개발 현황 (Pre-R&D): 규칙 기반 마케팅 자동화 도구

현재 1개 파일럿 매장에서 운영 중인 **규칙 기반 마케팅 자동화 도구**의 기능 구성:

| 기능 | 현황 | 한계 |
|------|------|------|
| **기능1: 고객 분류** | 월 1회 데이터 수집, 일반통계 규칙 기반 2분류 (안정/이탈 위험) | 수동 수집, 단순 규칙, 정밀도 한계 |
| **기능2: 문구 생성** | 사장님이 품목 선택 시 LLM이 400자 문구 생성 | AI 추천 부재, 일반 문구 |
| **기능3: 문자 발송** | 타겟 고객군 선택 후 수동 발송 | 수동 선택, 수동 발송 |

**현 시스템의 사장님 경험:**
> 뭐 팔지 고민 → 고객 고르기 → 문자 쓰기 → 발송 **(분석 → 판단 → 실행)**

## 3. 개발 목표 (본 과제): 자가학습 마케팅 루프 기반 AI 마케팅 운영체제

### 핵심 개념

> **본 시스템의 핵심은 AI 마케팅 어시스턴트를 통해 분석·판단·실행을 통합하고, 사장님의 복잡한 마케팅 의사결정을 즉시 실행 가능한 1~2개의 액션으로 단순화하는 데 있음.**

- 고객 데이터(CRM)와 상품 데이터(POS)를 통합하여 **'무엇을 · 누구에게 · 언제 판매할 것인지'** 자동 결정
- **자가학습 마케팅 루프**: 데이터 수집 → 고객/상품 분석 → 마케팅 액션 큐레이션 → 성과 학습 → 재추천

### 기능별 개발 목표

| 기능 | 현황 | 개발 목표 |
|------|------|----------|
| **기능1: 데이터 수집 + 고객 분류** | 월 1회 수동 / 일반통계 | **주 3회 자동 수집·정제 / ML 기반 복합 이탈 점수 모형** |
| | | • POS 연동 자동 데이터 수집 (주 3회) |
| | | • 고객 행동 기반 다차원 분류 |
| | | • 부위별 수요 변동 + 고객별 선호 패턴 분석 |
| **기능2: 개인화 문구 생성** | 사장님 품목 선택 / 일반 문구 | **AI가 홍보 품목 추천 / 정육점 특화 개인화 문구** |
| | | • AI 어시스턴트가 분석 결과 설명 및 액션 제안 |
| | | • 사실 오류 최소화, 정육점 특화 LLM 프롬프트 엔진 |
| | | • 개인화 깊이(Depth) 조절 옵션 |
| **기능3: 맞춤 문자 발송** | 수동 타겟 선택 / 수동 발송 | **AI가 맞춤 발송 리스트 추천 / 승인 즉시 발송** |
| | | • 홍보 품목 × 고객 패턴 × 개인화 깊이 연계 판단 |
| | | • 추천 → 승인 구조로 전환 |
| **기능4: 자가학습 최적화** | 없음 | **반응 추적 + 의사결정 최적화 엔진 (4~5단계)** |
| | | • 고객별 효과적 문구 패턴 및 발송 타이밍 기록 |
| | | • 고객군 × 품목 × 타이밍 결합 액션 추천 |
| | | • 예상 매출 효과 또는 반응률 수치 제시 |

### 도입 후 사장님 경험 변화

| 기존 | 도입 후 |
|------|--------|
| 뭐 팔지 고민 | 대시보드 접속 |
| 고객 고르기 | 오늘 할 마케팅 2개 확인 |
| 문자 쓰기 | 승인 |
| 발송 | 끝 |
| **(분석 → 판단 → 실행)** | **(추천 → 승인)** |

## 5. 확장 전략

본 시스템 완료 시 **고객 × 상품 × 타이밍** 기반 의사결정 구조를 갖추어, 채널·데이터·업종 확장이 자연스럽게 이루어지는 구조. 마케팅 의사결정이 특정 채널이나 업종이 아닌 **데이터 구조에 의해 정의**되기 때문에 가능한 확장임.

| 단계 | 확장 영역 | 내용 |
|------|----------|------|
| **1단계** | 예측 기반 마케팅 고도화 | 날씨·요일·이벤트 데이터 결합 사전 마케팅 |
| | | *"비 오는 날 삼겹살 수요 예상 → 사전 할인 이벤트 메시지 발송"* |
| | 채널 확장 | 앱푸시, 쿠폰 발행, 오프라인 이벤트 연동 |
| **2단계** | 업종 확장 | 정육점 → 식자재 유통 → 로컬 리테일 |
| | 플랫폼화 | AI 큐레이션 엔진 API 형태 제공, 다양한 리테일 사업자 연결 |

## 6. 단계별 개발 목표

| 단계 | 핵심 목표 | 주요 산출물 |
|------|----------|------------|
| **1단계** | ML 기반 이탈 예측 모형 개발 | 5개 매장 검증, 복합 이탈 점수 모형 |
| **2단계** | 품목별 수요 예측 모형 개발 | 부위별 수요 분석, 고객-품목 선호 매핑 |
| **3단계** | LLM 개인화 문구 생성 고도화 | 정육점 특화 프롬프트 엔진, 개인화 Depth 옵션 |
| **4단계** | 자가학습 기반 효과 검증 | A/B 테스트, 반응 추적, 의사결정 최적화 엔진 |
| **5단계** | AI 마케팅 운영체제 통합 | Zero-Task 대시보드, 추천→승인 UX 완성 |

## 7. 첫 적용 도메인: 정육점

| 선정 사유 | 설명 |
|----------|------|
