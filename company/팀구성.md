### 연구원별 과제수행 상세

#### 안동철 (연구책임자·대표이사)
- **담당 단계**: 전 단계 총괄
- **수행 업무**:
  - 연구 방향 설정 및 의사결정
  - 3단계 연구(1단계 모델 → 2단계 LLM vs 규칙 → 3단계 Depth 비교) 통합 관리
  - 특허 2~3건 출원 총괄
  - 파일럿 매장 1개→5개 확장 협력 관리
  - POS 데이터 연동 및 파이프라인 설계·구축
  - 멀티 매장 통합-개별 모델 전환 시스템 개발 (특허 3)
  - 문자 자동 발송 시스템 및 재방문 반응 윈도우 트래킹 구현

#### 배현혜 (연구소장)
- **담당 단계**: 1단계(모델 고도화), 2~3단계(실험 분석)
- **수행 업무**:
  - 방문주기 예측 RF1/RF2 모델 고도화 (현재 AUC 0.773 → 목표 0.80 이상)
  - F1 점수 0.70 이상 달성 (3개 매장 통합 기준)
  - 3등분 기반 개인별 이탈 기준 도출 방법론 정립 (특허 1)
  - 피처 엔지니어링 (방문간격 변화율, 객단가 변화율, 명절 더미변수 등)
  - 2단계 RCT 설계 및 분석 (이탈확률 50%+ 554명, LLM vs 규칙 A/B)
  - 3단계 LLM 개인화 Depth 1/2/3 비교 실험 분석
  - 패널 회귀/패널 로지스틱 회귀, Kruskal-Wallis 검정, 층화 분석
  - 복합 이탈 점수 산출 로직 고도화

#### Seo, Charles (연구원)
- **담당 단계**: 2단계(프롬프트 설계·품질 평가), 4~5단계(사용성·만족도)
- **수행 업무**:
  - LLM 개인화 Depth 1/2/3 프롬프트 설계 및 반복 검증 (특허 2 핵심 기여)
    - Depth 1: 이름 + 경과일 (~80자)
    - Depth 2: + 자주 사는 품목 (~120자)
    - Depth 3: + 방문 주기 + 구매 금액 + 단골 여부 (~180자)
  - 2단계 LLM vs 규칙 기반 문자 품질 어노테이션 (Cohen's Kappa 기반 평가자 간 신뢰도 확보)
  - 매장 사장님 대상 사용성 측정 (SUS, TAM, CES, NPS)
  - Think-aloud 프로토콜 진행 및 IPA(중요도-성과도) 분석
  - 디지털 취약산업 유저 대상 UX 최적화

#### 이지백 (연구원 - 현장협력)
- **담당 단계**: 전 단계 지원
- **수행 업무**:
  - 파일럿 매장 섭외 및 관계 관리 (1개 → 5개 확장)
  - 정육점 도메인 지식 자문 (부위-용도 매핑, 계절-고기 페어링 등 LLM 프롬프트에 반영)
  - 소상공인 네트워크 활용한 실증 확대
  - RCT 실험 현장 운영 지원 및 피드백 수집
  - 사업화 전략 수립 지원

#### 박동일 (연구보조원 - 행정)
