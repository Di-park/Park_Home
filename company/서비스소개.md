## 해결하려는 문제 (Problem)

정육점 등 소상공인은 다음과 같은 어려움을 겪고 있다:

1. **고객 관리의 부재**: 단골 고객 정보를 수기/기억에 의존. 누가 언제 뭘 샀는지 체계적으로 관리하지 못함
2. **마케팅 수단 부족**: 할인 행사, 신규 입고 등을 알리고 싶어도 개별 연락은 시간이 부족하고, IT 도구 활용이 어려움
3. **경험 기반 운영**: 재고·판매를 감으로 관리. 데이터 기반 의사결정(수요 예측, 인기 부위 분석 등)이 불가능
4. **IT 도구 접근성**: 기존 CRM/마케팅 도구는 소상공인에게 비싸고 복잡하며, 업종 특성을 반영하지 못함

## 솔루션 (Solution)

AI 에이전트가 정육점 점주의 **고객 관리, 마케팅, 판매 분석**을 자동으로 처리하는 서비스를 제공한다.
점주는 복잡한 IT 도구를 배울 필요 없이, 대화형 인터페이스로 간편하게 사용할 수 있다.

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **AI 고객관리 (CRM)** | 단골 고객 데이터 자동 수집·관리. 구매 이력, 선호 부위, 방문 주기 등 분석 |
| **자동 메시지 발송** | AI가 적절한 타이밍에 맞춤 메시지 자동 발송 (할인 안내, 입고 알림, 명절 인사 등) |
| **재고/판매 분석** | 판매 데이터 기반 재고 현황 파악, 인기 상품 분석, 수요 예측 |
| **대화형 인터페이스** | 점주가 챗봇처럼 대화하며 고객 조회, 메시지 발송, 매출 확인 가능 |

## 기술 스택

### AI/ML
- **LLM (대화형 에이전트)**: Claude API 또는 GPT - 점주와 자연어 대화, 고객 메시지 자동 생성
- **RAG (검색증강생성)**: 고객 데이터·판매 이력을 기반으로 맥락에 맞는 응답 생성 (LangChain / LlamaIndex)
- **수요 예측 모델**: 시계열 분석 기반 부위별 판매량 예측, 재고 최적화 (Prophet / scikit-learn)
- **고객 세분화**: 구매 패턴 기반 고객 군집 분석, 이탈 예측 (K-means, RFM 분석)

### Backend
- **API 서버**: Python + FastAPI - AI 모델 연동에 최적, 비동기 처리 지원
- **데이터베이스**: PostgreSQL (고객·판매 정형 데이터) + Redis (캐싱, 세션 관리)
- **메시지 큐**: Celery + Redis - 예약 메시지 발송, 비동기 분석 작업 처리
- **스케줄러**: 주기적 분석 리포트 생성, 자동 메시지 발송 트리거

### Frontend / 점주 인터페이스
- **모바일 웹앱**: React 또는 Next.js - 점주가 스마트폰으로 바로 접근
- **카카오 채널 연동**: 카카오톡 채널 API - 점주가 가장 익숙한 인터페이스에서 에이전트와 대화
- **관리 대시보드**: 매출 현황, 고객 분석, 메시지 발송 이력 시각화

### 메시징/알림
- **카카오 알림톡/친구톡 API**: 고객에게 할인, 입고 안내 등 메시지 자동 발송
- **SMS API** (NHN Cloud / CoolSMS): 카카오톡 미사용 고객 대상 문자 발송 fallback

### Infra / DevOps
- **클라우드**: AWS (EC2, RDS, S3) - 확장성과 비용 효율
- **컨테이너**: Docker + Docker Compose - 개발/배포 환경 일관성
- **CI/CD**: GitHub Actions - 자동 빌드, 테스트, 배포
- **모니터링**: Sentry (에러 추적) + CloudWatch (인프라 모니터링)

## 핵심 기술 / 차별점
1. **업종 특화**: 범용 CRM이 아닌 정육점(식품 소매) 현장에 최적화된 기능 제공
2. **AI 에이전트**: 단순 도구가 아닌, 점주 대신 판단하고 실행하는 자율형 에이전트
3. **제로 러닝커브**: IT 비전문가도 대화만으로 사용 가능한 인터페이스
4. **데이터 기반 인사이트**: 감 대신 데이터로 운영 의사결정 지원
5. **자체 예측 모델**: 방문주기·이탈 예측 모델 자체 개발 (현재 AUC 0.773, 목표 0.80 이상)
6. **지식재산 확보**: 이탈 정의 체계 · LLM 개인화 · 멀티매장 모델 전환 관련 특허 2~3건 출원 계획

## 실증 / 트랙션
- **파일럿 매장 운영**: 실제 정육점 파일럿 매장 데이터 기반으로 모델 학습·검증 (1개소 → 5개소 확장 계획)
- **효과 검증(RCT) 설계**: 이탈확률 50% 이상 고객 554명 대상 LLM vs 규칙 기반 문자 A/B 테스트로 재방문 효과 실증
- **유통 파트너십**: 연 매출 약 1,000억 원 규모 정육 유통기업 **㈜더담우**와 파일럿 매장 확보·영업 네트워크 협력
