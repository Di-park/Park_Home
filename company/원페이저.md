# WeaveOne (주식회사 위브원)

## 정육점 AI 고객관리 에이전트

**"단골 관리, AI가 대신합니다"**

---

## Problem

소상공인 정육점 점주는 IT 기술의 혜택을 누리지 못하고 있습니다.

- 단골 고객 정보를 **기억과 수기**에 의존
- 마케팅 하고 싶어도 **시간과 IT 역량 부족**
- 기존 CRM 도구는 **비싸고 복잡**하며 업종 특성 미반영

---

## Solution

AI 에이전트가 **고객 관리, 마케팅, 판매 분석**을 자동으로 처리합니다.

| 기능 | 설명 |
|------|------|
| AI 고객관리 | 단골 데이터 자동 수집, 구매 이력·선호 부위 분석 |
| 자동 메시지 발송 | AI가 적절한 타이밍에 맞춤 메시지 자동 발송 |
| 이탈 예측 | 이탈 위험 고객 조기 감지, 선제적 리텐션 |
| 대화형 인터페이스 | IT 비전문가도 대화만으로 사용 가능 |

---

## 차별점

1. **업종 특화** - 정육점 현장에 최적화된 기능
2. **AI 에이전트** - 단순 도구가 아닌 자율형 에이전트
3. **제로 러닝커브** - 대화만으로 사용 가능
