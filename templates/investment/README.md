# 투자유치용 사업계획서 템플릿

이 디렉토리에는 VC/엔젤 투자유치를 위한 사업계획서 템플릿이 포함되어 있습니다.

## 포함 템플릿
- `사업계획서_템플릿.md` - 투자유치용 사업계획서 기본 템플릿 (송부·문서용, 상세)
- `IR_덱_템플릿_Seed.md` - Pre-Seed / Seed 라운드 IR 덱(피칭용 슬라이드) 템플릿, 12~15장 구성

## 사용 가이드
- **사업계획서**는 읽는 문서(상세, 텍스트 중심)
- **IR 덱**은 발표용 자료(슬라이드 1장 = 메시지 1개)
- 보통 두 가지를 함께 준비하며, IR 덱이 1차 컨택, 사업계획서는 후속 자료로 사용

## 관련 체크리스트
- `checklists/IR덱_체크리스트.md` - IR 덱 출시 전 슬라이드별/디자인/발표 점검
- `checklists/투자유치_체크리스트.md` - 사업계획서 전반 점검
